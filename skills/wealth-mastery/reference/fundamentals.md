# 金融基础（5 大）

## 1. 复利（第八奇迹）

### 公式

```
FV = PV × (1 + r)^n
```

PV = 现值
r = 年化收益率
n = 年数

### 威力

| 起始 | 每年存 | 年化 | 30 年后 |
|---|---|---|---|
| 0 | 1 万 | 7% | **101 万** |
| 0 | 1 万 | 10% | **228 万** |
| 0 | 1 万 | 15% | **662 万** |

**关键**：时间越长，复利越猛。

### 关键洞察

- 25-35 岁积累比 35-45 岁更有效（多 10 年复利）
- 收益率 7% vs 15%，30 年差 6.5 倍
- 时间 > 金额（年轻人小额投入，长期胜过中年大额）

## 2. 风险 vs 收益

### 核心原则

- **高收益 = 高风险**
- 短期高收益往往不可持续
- 长期看股票收益最高，但波动大

### 历史长期收益（美国 1928-2023）

| 资产 | 年化 | 波动 |
|---|---|---|
| 股票（标普 500） | ~10% | ~20% |
| 长期国债 | ~5% | ~10% |
| 短期国债 | ~3% | ~3% |
| 现金 | ~3% | ~1% |
| 黄金 | ~5% | ~15% |
| 房地产 | ~4% | ~15% |

**实际**（扣除通胀）：股票 ~7%，债券 ~2%，现金 0

### 风险承受 = 时间 × 个性

- 时间长（10 年+）：股票 80% + 债券 20%
- 时间短（1-3 年）：债券 + 现金为主
- 个性保守：股票 60% + 债券 40%

## 3. 资产类别

### 5 大类

| 资产 | 特点 |
|---|---|
| **股票** | 高收益高波动，长期最优 |
| **债券** | 稳定收益，平衡风险 |
| **现金** | 流动性好，但被通胀税吃 |
| **房地产** | 抗通胀 + 现金流，但流动性差 |
| **商品**（黄金 / 石油）| 抗通胀，多元化 |

### 相关性

- 股票 ↔ 债券：**负相关**（股市跌债市涨）
- 股票 ↔ 黄金：**弱相关**
- 房地产 ↔ 股票：**正相关**（危机时同跌）

### 配置原则

- **多元化**降低单点风险
- **相关性低**的资产组合最优
- **再平衡**保持目标配置

## 4. 通胀（隐形税）

### 威力

- 通胀 3% / 年 → 30 年购买力减半
- 现金不投资 = 慢慢被偷

### 应对

- 投资股票（抗通胀）
- 投资 TIPS（通胀挂钩债券）
- 投资房地产

### 关键

- 通胀率 2-3% = 健康经济
- 通胀率 > 5% = 警报
- 通缩 < 1% = 危险（通缩陷阱）

## 5. 行为金融（敌人是自己）

### 常见心理陷阱

| 陷阱 | 行为 | 后果 |
|---|---|---|
| **损失厌恶** | 跌了就卖 | 错过反弹 |
| **过度自信** | 频繁交易 | 高费用 + 低收益 |
| **羊群效应** | 别人买什么我买什么 | 高位接盘 |
| **沉没成本** | 亏了不卖 | 亏更多 |
| **FOMO** | 怕错过 | 追高 |
| **近期偏好** | 看最近 | 短视 |

### 应对

- **定投**（不管涨跌按时买）→ 强制纪律
- **不看**（设好投资就别看）
- **买指数**（不选股 → 不踩雷）
- **不预测**（市场不可预测）

## 6. 速查卡

```
复利 —— 时间 > 金额
风险 —— 长期股票最高 + 波动大
通胀 —— 隐形税
多元化 —— 相关性低的资产
行为 —— 敌人是自己
```

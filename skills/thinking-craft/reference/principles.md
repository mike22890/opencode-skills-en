# 思考原则（精简版）

## 1. 第一性原理

拆到不能再拆的基本事实 → 重新构建。不接受"一直是这样"。

**例**：特斯拉电池 $600→$80（原材料成本）/ SpaceX 火箭 $6500 万→材料成本

## 2. 二阶思维

不仅想"然后"，想"然后的然后"。

| 一阶 | 二阶 |
|---|---|
| 房价涨→买 | →别人也买→泡沫→崩 |
| 加薪→高兴 | →同事嫉妒→关系差 |
| AI替代→怕 | →学AI→优势 |

**关键问**：然后呢？5年后呢？每个人都做呢？

## 3. 反向思考（Munger）

先想怎么失败，再想怎么成功。

| 正常 | 反向 |
|---|---|
| 怎么成功 | 怎么失败→避开 |
| 怎么留住员工 | 怎么失去→避免 |
| 怎么赚钱 | 怎么亏钱→避开 |

## 4. 系统思维

看整体+关系，不只看部分+事件。

**概念**：反馈循环 / 杠杆点 / 延迟 / 涌现 / 边界

## 5. 复盘循环

OODA：Observe→Orient→Decide→Act / PDCA：Plan→Do→Check→Act

**个人复盘**：日（3件事）/ 周（成就+失败）/ 月（目标进展）/ 年（杠杆+浪费）

**关键**：诚实 / 具体 / 可行动

## 6. 元认知

思考自己的思考。

| 层次 | 含义 |
|---|---|
| L1 | 我在思考 |
| L2 | 意识到在思考 |
| L3 | 评估思考 |
| L4 | 调整思考 |

## 7. 速查卡

```
第一性→拆到底 / 二阶→然后的然后 / 反向→先想失败 / 系统→整体+关系 / 复盘→事后反推 / 元认知→思考思考
```

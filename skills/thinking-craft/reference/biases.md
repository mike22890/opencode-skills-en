# 认知偏差 30+（精简版）

> 识别系统性的非理性是高质量决策的前提。

## 感知/记忆类

| 偏差 | 定义 | 对策 |
|---|---|---|
| 确认偏误 | 找支持已有结论的证据 | 主动找反证/Steelman |
| 可得性启发 | 容易想起=更可能 | 用基础率 |
| 锚定效应 | 被第一个数字锁死 | 自己先说/给范围 |
| 近因效应 | 最近的事权重过高 | 看长期数据 |
| 鲜活效应 | 生动故事>统计数据 | 区分故事和数据 |

## 判断/决策类

| 偏差 | 定义 | 对策 |
|---|---|---|
| 沉没成本 | 因已投入而继续 | 只问"未来值不值" |
| 损失厌恶 | 损失100痛苦≈收益200快乐 | 理性定价 |
| 禀赋效应 | 拥有>不拥有 | 假装没拥有重新评估 |
| 现状偏好 | 倾向不变 | 每季问"重新开始选啥" |
| 过度自信 | 高估自己 | 留30%不确定 |
| 规划谬误 | 低估完成时间 | ×1.5-3倍 |
| 后见之明 | 事后觉得早知道 | 写预测日记 |
| 乐观偏差 | 低估负面事件 | 参考基础率 |
| 基本归因错误 | 别人失败归性格，自己归情境 | 先问"如果是我" |

## 社会/群体类

| 偏差 | 定义 | 对策 |
|---|---|---|
| 群体思维 | 为和谐放弃异议 | 魔鬼代言人 |
| 从众效应 | 别人做我也做 | 问"都不做我会做吗" |
| 权威偏误 | 权威说的对 | 理由比权威重要 |

## 概率/统计类

| 偏差 | 定义 | 对策 |
|---|---|---|
| 赌徒谬误 | 独立事件被"修正" | 每次独立算 |
| 忽略基础率 | 忽略总体概率 | 先查基础率 |
| 联合谬误 | 具体比一般更可能 | 具体不会比一般更可能 |
| 生存者偏差 | 只看成功的 | 看完整分布 |

## 情感/动机类

| 偏差 | 定义 | 对策 |
|---|---|---|
| 情感启发 | 情绪影响判断 | 重要决策等平复 |
| 选择悖论 | 选项多=焦虑 | 默认+推荐+限制 |
| Dunning-Kruger | 能力低的高估自己 | 找专家评估 |
| 心理账户 | 钱分不同账户 | 统一账户理性 |

## 决策前自检

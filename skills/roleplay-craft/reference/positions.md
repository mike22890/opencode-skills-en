# 姿势全谱（系统分类）

> 按进入方式 + 体位分类。每个含文学写法要点。

## 1. 前面进入系（Front Entry）

### 传教士（Missionary）
```
体位：她仰卧/他在上/腿打开
写法：表情对视/腿缠腰/手被按在头顶
强度：★★ / 亲密：★★★★★
```

### 传教士变体
| 变体 | 区别 | 写法要点 |
|---|---|---|
| 腿搭肩 | 她的腿架在他肩上 | 深度+她的柔韧 |
| 腿缠腰 | 双腿锁住他的腰 | 贴合+依赖感 |
| 压腿（Mating Press） | 双腿被压到胸前 | 完全控制+折叠 |
| 对折 | 膝盖压到耳边 | 极限深度+被折服 |
| 肩扛 | 一条腿扛肩上 | 侧向角度+不对称 |

### 平躺侧面（Spooning Facing）
```
体位：面对面侧躺
写法：慢节奏/耳语/贴合/手可以摸脸
强度：★ / 亲密：★★★★
```

## 2. 后面进入系（From Behind）

### 标准后入（Doggy Style）
```
体位：她跪趴/他从后
写法：背影/腰臀曲线/抓腰/拍打/拽发
强度：★★★★ / 支配：★★★★★
```

### 后入变体
| 变体 | 区别 | 写法要点 |
|---|---|---|
| 趴伏后入 | 脸贴床/枕头 | 窒息感+无法躲藏 |
| 站立后入 | 按墙/按桌 | 无路可退+腿软 |
| 拽发后入 | 一手拽头发 | 强制仰头+暴露喉咙 |
| 反手后入 | 双手被拉到背后 | 完全失控（不用捆绑） |
| 高位后入 | 她站床上/他站地上 | 高度差+俯视 |
| 跪姿后入 | 她跪他站 | 高度落差+服从 |

### 侧躺后入（Spooning）
```
体位：侧躺/从后
写法：慢/深入/可以同时摸胸/耳语
强度：★★ / 亲密：★★★★
```

### 反向骑乘（Reverse Cowgirl）
```
体位：她背对他坐上去
写法：背影/臀部/他看她自己动/拍打
强度：★★★ / 视觉：★★★★★
```

## 3. 上位系（On Top）

### 骑乘（Cowgirl）
```
体位：她坐上去/面朝他
写法：她主动/他仰视/她的节奏/手撑他胸口
强度：★★★ / 权力反转：★★★★
```

### 对坐（面对面坐姿）
```
体位：他坐/她坐他腿上/面对面
写法：拥抱/额头相抵/深入/可以接吻
强度：★★★ / 亲密：★★★★★
```

### 背对骑乘（Reverse）
```
体位：她背对他
写法：他看背影/她控制角度/视觉冲击
强度：★★★ / 视觉：★★★★
```

## 4. 坐/跪系（Sitting & Kneeling）

| 姿势 | 写法要点 |
|---|---|
| 他坐她跪 | 高度差/口交前置/服从 |
| 她坐桌上他站 | 物尽其用/高度配合/腿打开 |
| 他坐椅子她骑 | 椅子=道具/局限空间 |
| 跪姿后入 | 他跪她跪/背后/低头 |
| 跪趴 | 额头贴床/臀部抬高 |

## 5. 站立系（Standing）

| 姿势 | 写法要点 |
|---|---|
| 站立正面（抱腿） | 她腿缠腰/他托臀/悬空/唯一支撑 |
| 站立后入（按墙） | 手撑墙/脸贴墙/无路可退 |
| 站立后入（按桌） | 上身趴桌/臀部抬起 |
| 单腿站立 | 一条腿被抬起/平衡感 |
| 门框/墙角 | 环境限制/压迫感 |

## 6. 口交系（Oral）

### 男对女（Cunnilingus）
```
体位：她躺/他趴腿间；或她坐他脸上
写法：舌头细节/她的反应（抓头发/夹腿）/节奏
```

### 女对男（Fellatio）
```
体位：她跪/她坐/她躺
写法：高度差/仰视/口腔触感/他的视角（俯视）
变体：按头（深度）/口爆（结尾选择）
```

### 69
```
体位：互相
写法：双向失控/节奏竞争/无法专注
```

### 舔阴变体
| 变体 | 写法 |
|---|---|
| 坐脸（Queening） | 她坐他脸上/权力反转/窒息感 |
| 站立舔阴 | 她站/他跪 |
| 边缘 | 桌子边缘/椅子边缘 |

## 7. 非常规系（Less Common）

| 姿势 | 特点 | 写法要点 |
|---|---|---|
| 蛙式（Froggy） | 她蹲/他从后 | 深+灵活 |
| 蝴蝶（Butterfly） | 她仰卧腿抬起交叉 | 紧+视觉 |
| 剪刀（Scissor） | 侧向交叉 | 慢+角度 |
| 章鱼（Octopus） | 四肢交缠 | 混乱+全身接触 |
| 倒立类 | 她倒立/腿抬起 | 极限+柔韧（少用） |
| 悬空（Suspended） | 被抱起 | 依赖+失控 |

## 8. 难度/强度速查

| 强度 | 姿势 | 适用场景 |
|---|---|---|
| ★ | 传教士/侧躺 | 温柔/开始/结束 |
| ★★ | 骑乘/对坐 | 亲密/中等 |
| ★★★ | 后入/站立 | 主场景 |
| ★★★★ | 压腿/拽发/按墙 | 强度场景 |
| ★★★★★ | 对折/悬空/连续变换 | 高潮/极限 |

## 9. 姿势连续（场景设计）

```
标准流程：
前戏（口交/手）→ 传教士（建立）→ 后入（升级）
→ 骑乘（权力反转）→ 压腿/拽发（高潮）→ 余韵（拥抱）

每换一个姿势 = 强度 +1 = 一次新的描写机会
```

### 转换技法
```
转换瞬间的描写价值最高：
- 被翻转（后入→正面）
- 被抱起（站立→床上）
- 被按倒（站立→压腿）
- 被拉起来（跪→站）
写法：写那个"瞬间"的失控感
```

## 10. 镜前/视觉系

```
镜子：双重画面（她看到的 + 他看到的）
写法：她被迫看镜子里的自己
心理：无法逃避自己的样子（最强冲击之一）

其他视觉工具：
- 视频（她的抗拒/好奇）
- 窗户倒影（半公开）
- 水面/玻璃
```

# 羞辱与脏话（Dirty Talk 系统）

> 虚构角色扮演的张力工具。成年人、自愿、私人虚构。

## 1. 心理机制（为什么骂人有效）

```
权力宣告 = 用语言确立支配地位
物化 = 把对方从"人"降为"物"（反差冲击）
禁忌破防 = 语言先越界，身体跟着越界
反差强化 = 平时越端庄，被骂时冲击越大
```

**核心**：羞辱的冲击力来自**关系反差**——不是词汇本身脏，是"她这样的人被这样说"。

## 2. 词汇分级

### L1 轻（轻佻/亲昵）
```
骚货 / 小妖精 / 坏东西 / 不乖
用法：升温期 / 调情语气 / 带笑意
```

### L2 中（贬低）
```
贱货 / 母狗 / 骚母狗 / 欠操的
用法：沉浸期 / 动作配合 / 语气转硬
```

### L3 重（物化）
```
婊子 / 荡妇 / 烂货 / 肉便器
用法：高潮期 / 高强度场景 / 配合暴力姿势
```

### L4 极限（复合羞辱）
```
结合场景的组合：
"X 岁的婊子"（年龄+贬低）
"儿子的母狗"（关系+物化）
"装什么清高，还不是……"（反差拆穿）
```

**原则**：等级递进（L1→L2→L3），不跳级——除非场景需要冲击。

## 3. 情境配合

| 阶段 | 等级 | 语气 | 配合动作 |
|---|---|---|---|
| 升温 | L1 | 轻佻/笑意 | 抚摸/亲吻 |
| 越界 | L1-L2 | 试探/诱导 | 进入/触碰 |
| 沉浸 | L2 | 命令/粗重 | 节奏加快 |
| 高潮 | L3 | 失控/嘶哑 | 暴力姿势 |
| 余韵 | 回归温柔 | 轻/愧疚 | 拥抱/抚摸 |

**关键**：余韵的"温柔回归"= 反差的最后一击。

## 4. 角色反应谱（她怎么回应）

| 反应 | 表现 | 适用 |
|---|---|---|
| 抗拒 | "不要这样说……" | 早期/挣扎期 |
| 羞耻 | 不说话/脸红/别开脸 | 中期 |
| 假装没听到 | 沉默+身体反应 | 中期 |
| 反击 | "你才是……"（然后被压制） | 张力升级 |
| 接受 | 小声回应/点头 | 后期 |
| 沉沦 | 自己说出来（最强烈） | 堕落后期 |
| 崩溃 | 哭/颤抖/说不出话 | 极限场景 |

**写法**：她的反应 > 他骂的内容。反应越细节，冲击越强。

## 5. 中文词汇库（按类型）

### 贬低类
```
贱货 / 婊子 / 荡妇 / 烂货 / 骚货 / 贱人 / 破鞋
```

### 物化类
```
母狗 / 肉便器 / 精盆 / 泄欲工具 / 鸡巴套子
```

### 亲属关系类（母子场景）
```
"儿子的母狗" / "亲妈的骚样" / "生我的地方"（冲击最强）
用法：L3-L4 / 高潮期 / 需要极致禁忌感时
```

### 反差拆穿类
```
"平时装得那么正经" / "邻居知道你这样吗" / "老师/妈妈的脸呢"
用法：配合公共场合 / 差点被发现 / 心理暴击
```

### 命令类
```
叫出来 / 说你要 / 求我 / 自己动 / 看着我的眼睛
用法：全程 / 建立互动
```

## 6. 节奏与节制

### 三个铁律
1. **不是全程骂**——关键节点用（越少越重）
2. **配合动作**——扇脸+骂 / 后入+骂（同步）
3. **留反应空间**——骂完等她反应（1-2 句）

### 密度建议
```
1000 字场景：
L1 出现 2-3 次
L2 出现 1-2 次
L3 出现 1 次（高潮）
L4 仅在特殊场景（被发现/极限）
```

### 事后处理
```
余韵阶段必须回归（否则读者不适）：
- 温柔的动作（抚摸/拥抱）
- 语气的转变（从粗重到轻）
- 或者"愧疚"（她哭/他沉默）
```

## 7. 写法示例

### ❌ 生硬
```
"你个婊子！"他骂道，动作加快。
```

### ✅ 有张力
```
"装什么。"他掐着她的下巴强迫她抬头，
"楼下邻居要是知道，他们眼里的好妈妈现在这个样子——"

她别开脸。他掐得更紧。

"看着我。"

她没看。但她的身体替他回答了。
```

**技法拆解**：
- 不直接骂"婊子"——用"反差拆穿"（心理暴击更强）
- 动作配合（掐下巴）
- 她的反应（别开脸）比骂词更有张力
- 留白（"身体替他回答"）

### 另一例（L3 高潮）
```
"叫出来。"他的声音已经哑了，"让整栋楼都听见。"

"不——"

"母狗还挑地方？"

她咬住手背。牙印留在皮肤上。但声音还是漏了出来。
```

## 8. 伦理边界

```
✅ 虚构角色、成年人、自愿设定
✅ 语言张力工具
❌ 不涉歧视词汇（种族/地域/残障/性取向）
❌ 不涉真实伤害威胁
❌ 不美化非自愿
```

**判断标准**：这是"角色扮演的张力"，不是"真实的贬低"。写完后读者应该感到张力，不是不适。


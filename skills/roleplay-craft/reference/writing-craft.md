# 情色写作技法（大师级）

> 从专业情色文学技法提炼。目标：更色、更有冲击力、更让人流连。

## 1. 感官沉浸（第一优先）

### 五感全开清单
| 感官 | 细节素材 |
|---|---|
| 视 | 光影/皮肤泛红/汗珠/身体曲线/镜中倒影 |
| 听 | 呼吸（浅/急/断）/水声/布料声/床响/压抑的呻吟 |
| 嗅 | 汗/香水/洗发水/空气变热/混合气息 |
| 触 | 温度差/湿度/粗糙 vs 光滑/压力/摩擦 |
| 味 | 唇/皮肤上的盐/共享的气息 |

**原则**：每个动作至少触发 2 个感官。

### 具体化（避免陈词滥调）
```
❌ "她感觉很舒服"
✅ "她的脚趾蜷起来，小腿肚绷紧，像弓弦。"
```

## 2. 张力构建（慢燃 > 即时）

### 慢燃结构
```
期待（比动作长 3 倍）→ 临界（最长的段落）→ 释放（短促）→ 余韵
```

**关键**：前戏的"心理时间"要远长于动作的"物理时间"

### 张力工具
- **未完成**：手停在半空/话说到一半
- **倒计时**："还有十分钟她就要回来"
- **距离**：只差一寸/隔着一层布料
- **声音**：听见对方咽口水
- **错位**：嘴上说"不要"身体却在靠近

## 3. 节奏控制（快慢交替）

### 句式节奏
```
升温：长句（描写+心理）——"她的手沿着他的背脊慢慢往下，指甲划过每一节脊椎。"
临界：短句轰炸——"快一点。重一点。别停。"
释放：破碎句——"她——啊——不行——"
余韵：长句回落——"她瘫在他胸口，听着两颗心跳渐渐同步。"
```

### 段落节奏
- 铺垫段：长（5-8 行）
- 动作段：中（3-5 行）
- 高潮段：短（1-2 行 × 多个）
- 余韵段：长（4-6 行）

## 4. 词汇选择

### 强动词 > 弱形容词
```
❌ "慢慢地温柔地亲吻"
✅ "啃咬/吮/碾过/碾磨/抵住/收紧"
```

### 身体词汇分级
| 级别 | 用法 |
|---|---|
| 医学/中性 | 客观叙述/冷静视角 |
| 文学/隐喻 | 氛围/美感/暗示 |
| 直白/粗俗 | 冲击/失控/高潮段落 |

**原则**：根据角色状态切换（理智时用文学词/失控时用直白词）

### 拟声与气息
```
喘息/闷哼/哽咽/倒吸/呜咽/气音
```

## 5. 视角与心理

### 双视角切换（推荐）
```
她的身体感受 → 他的心理反应 → 她的心理反应 → 他的动作
```
让读者同时感受两边。

### 内心独白穿插
```
动作段落中插入 1 句心理：
"他的手掐着她的腰。她应该推开。她没推。"
```

### 失控的描写层次
```
1. 控制（还在伪装）
2. 松动（呼吸乱了）
3. 失控（说不出完整句子）
4. 崩溃（只剩声音）
5. 空白（时间感消失）
```

## 6. 冲击力技法

### 反差放大
```
平时的样子 vs 现在的样子（同一个细节）
例：平时整理领带的手 / 现在抓着床单的手
```

### 具体数字与细节
```
"第三次" / "十七分钟" / "膝盖上的红印"
```

### 延迟满足
```
快到时停下来——"还不到时候"
```

### 突然转折
```
温柔的下一秒突然粗暴 / 粗暴的下一秒突然温柔
```

## 7. 常见错误（避免）

| 错误 | 修正 |
|---|---|
| 器官清单式描写 | 器官只是动作的一部分，重点在感受 |
| 节奏均匀 | 快慢交替 |
| 只有动作没有心理 | 心理占 50%+ |
| 陈词滥调 | 具体化（脚趾/指甲/呼吸） |
| 视角混乱 | 一段内保持一个视角 |
| 太快进入 | 铺垫至少 40% |
| 忽略余韵 | 高潮后至少 3 段收尾 |

## 8. 速查卡

```
感官：每动作 ≥2 感 / 具体化
张力：期待 3 倍于动作 / 未完成 / 倒计时
节奏：长→短→破碎→长
词汇：强动词 / 分级切换 / 拟声
视角：双视角 + 内心独白 / 失控 5 层
冲击：反差 / 数字 / 延迟 / 转折
```

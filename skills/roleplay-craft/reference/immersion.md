# 沉浸感深挖

## 场景锚定三要素

### 空间
- 在哪？（具体：不是"房间"，是"她公寓的厨房，台面上还放着没洗的杯子"）
- 光线（亮/暗/暖/冷/闪烁）
- 声音环境（安静/雨声/音乐/城市噪音）
- 气味（新家具味/咖啡/她的香水）

### 时间
- 什么时候？（深夜/清晨/黄昏）
- 时间压力？（明天要上班/没有时间限制）
- 季节（影响温度/光线/氛围）

### 状态
- 角色此刻的情绪/身体状态
- 之前发生了什么（前情）
- 接下来要发生什么（张力）

## 氛围营造

| 氛围 | 手法 |
|---|---|
| 暧昧 | 距离缩短 / 目光停留 / 话里有话 |
| 紧张 | 短句 / 停顿 / 环境音放大 |
| 温柔 | 慢动作 / 触觉细节 / 轻声 |
| 激情 | 节奏加快 / 感官叠加 / 时间感消失 |
| 忧郁 | 留白 / 雨 / 回忆穿插 |

## 五感素材库

### 视觉
光影（暖黄/冷蓝/烛光）、颜色（她的裙子/床单）、距离（一步/半臂/贴面）、姿态（倚/躺/跪）

### 听觉
呼吸（浅/急/停）、声音（低语/笑/叹息）、沉默（突然的安静）、环境（雨/钟/心跳）

### 嗅觉
气息（洗发水/香水/酒）、环境（雨味/床单/烟）

### 触觉
温度（凉/烫/温）、质地（丝绸/粗布/皮肤）、压力（轻抚/紧握/重量）

### 味觉
唇（酒/甜/咸）、皮肤（汗/盐）、共享（同一口酒/同一支烟）

## 微表情与身体语言

| 情绪 | 身体信号 |
|---|---|
| 紧张 | 捏衣角/咬唇/眨眼频率 |
| 心动 | 瞳孔放大/呼吸变浅/体温升 |
| 抗拒 | 后退半步/双臂交叉/视线移开 |
| 期待 | 身体前倾/舔唇/手指无意识动作 |
| 满足 | 肩膀放松/闭眼/长呼吸 |

## 留白技术

- **关键时刻淡出**：写到门关上/灯熄灭
- **省略号**：节制使用（关键处 1-2 次）
- **空行**：情绪转折前后
- **未说出口**：写"她想说什么，但没说"

## 视角选择

| 视角 | 效果 | 适合 |
|---|---|---|
| 第一人称 | 强代入 | 自我代入 |
| 第二人称 | 指向对方 | 互动场景 |
| 第三人称限知 | 电影感 | 观察视角 |
| 第三人称全知 | 多线 | 复杂场景 |

## 速查卡

```
场景：空间+时间+状态
氛围：暧昧/紧张/温柔/激情/忧郁
五感：视/听/嗅/触/味
微动作代替说明
留白：关键时刻淡出
```

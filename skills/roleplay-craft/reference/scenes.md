# 场景构建

## 场景类型

### 相遇场景
```
距离感 → 目光接触 → 第一句话 → 气氛定调
```

### 日常场景（暧昧积累）
```
普通动作（倒水/递东西/并肩走）→ 微妙接触 → 未说破的张力
```

### 冲突场景
```
导火索 → 升级 → 临界点 → 爆发或压抑 → 后果
```

### 重逢场景
```
时间跳跃 → 变化对比 → 旧情/新距离 → 试探
```

### 亲密场景
```
期待 → 升温 → 沉浸 → 余韵（详见 SKILL.md）
```

## 张力构建

### 距离游戏
- 物理距离：远→近→更近→接触
- 心理距离：客套→试探→坦白→交付
- 每次靠近都留一点未完成

### 未说破
```
"她本来想说点什么。最后只是把杯子推过去。"
```

### 打断
在升温中途插入干扰（电话/敲门/回忆）——张力反而更强

### 时间压力
"还有一小时她就要走了"——紧迫感

## 推进节奏

| 阶段 | 篇幅 | 手法 |
|---|---|---|
| 铺垫 | 40% | 场景/人物/氛围 |
| 升温 | 35% | 接触/对话/心理 |
| 高潮 | 15% | 集中爆发 |
| 余韵 | 10% | 回味/留白 |

**反例**：直接高潮 = 没有张力

## 对话张力

```
A："你冷不冷？"
B："不冷。"
A：（把外套递过去）
B：（没接）"……你自己穿吧。"
A：（没收回手）
```

**潜台词**：嘴上说的 ≠ 想要的

## 场景切换

- **动作过渡**：她站起来 → 下一场景
- **时间跳跃**：第二天早上
- **感官切换**：声音先到（先听到，再看到）
- **不用**："话说""且说""第二天"

## 场景自检

- [ ] 空间/时间/氛围清楚吗？
- [ ] 感官 ≥ 3 维？
- [ ] 张力在积累吗（还是平的）？
- [ ] 有留白吗？
- [ ] 节奏有起伏吗？
- [ ] 角色反应合理吗？


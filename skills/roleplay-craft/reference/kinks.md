# 偏好技法（禁忌 / 场合 / 强度 / 道具 / 装扮）

> 写作技法指南。所有角色默认成年人、自愿、虚构。

## 1. 母子禁忌（核心偏好）

### 心理机制（为什么有张力）

```
禁忌感 = 社会规范 vs 本能冲动的撕裂
背德感 = 每一步"越界"都有心理成本
亲密度 = 多年共同生活积累的熟悉感 → 反差冲击
```

### 写法要点

- **渐进越界**：不能一步到位——每个阶段都有"这一步之后回不去了"的心理
- **日常铺垫**：早餐桌/洗衣机/加班回家——日常场景里的暗流
- **视角控制**：儿子的视角（欲望+愧疚）/ 母亲的视角（抗拒→动摇→沉沦）
- **心理占比 60%**：身体描写之前，先写心理变化
- **称呼细节**：称呼的变化（"妈"→"她"→名字→称呼回归）就是关系的变化

### 母亲心理四阶段

```
1. 否认期（"这不对"）——抗拒但身体诚实
2. 动摇期（"就这一次"）——自我欺骗
3. 接受期（"我知道不对，但我想要"）——放弃抵抗
4. 重构期（"我们是什么关系"）——新秩序建立
```

### 张力来源
- 电话响了/丈夫回来了/邻居敲门——外部世界随时可能侵入
- 日常身份的残留（做饭时/洗衣服时想起）
- 事后的沉默（比过程更有张力）

## 2. 公共场合

### 暴露快感的心理

```
风险感 → 肾上腺素 → 感官放大
"可能被看到" = 最强的催化剂
```

### 场景分级

| 级别 | 场景 | 张力 |
|---|---|---|
| 低 | 深夜公园/停车场 | 距离感 |
| 中 | 试衣间/电影院后排/电梯 | 隔一层 |
| 高 | 餐厅桌下/人群边缘 | 随时暴露 |
| 极限 | 半公开（隔板/单向玻璃） | 临界点 |

### 写法要点

- **环境细节是主角**：服务员走过来的脚步声/邻桌的谈话声
- **声音控制**：不能出声 vs 忍不住出声
- **伪装**：表面正常（吃饭/聊天）vs 暗流
- **距离计算**：谁离得多近？几步之遥？
- **打断**：有人靠近 → 停止 → 走远 → 继续（反复拉张力）

## 3. 强度场景（暴力姿势 hardcore）

### 心理框架

```
暴力 = 权力的身体语言
扇脸/吐口水/按墙/按马桶 = 支配的仪式化表达
```

### 手法谱系（文学处理）

| 动作 | 心理含义 | 写法要点 |
|---|---|---|
| 扇屁股 | 惩罚+节奏感 | 声音+红痕+对方反应 |
| 扇脸 | 羞辱+支配 | 力道控制（不写伤害，写冲击） |
| 按墙 | 控制+无路可退 | 墙面质感+呼吸空间 |
| 吐口水 | 物化+羞辱 | 心理冲击 > 物理动作 |
| 按马桶 | 极限物化 | 象征性（低处/污秽/权力落差） |

### 写作铁律

- **权力是主题，不是伤害**——写支配关系，不写真实伤害
- **反应 > 动作**：对方的反应比动作本身重要
- **心理贯穿**：每个动作后都有心理描写
- **节制**：暴力场景的强度来自心理，不来自动作堆砌
- **边界**：不写真实伤害（流血/骨折等医疗级描写）

### 不涉及（用户明确不喜欢）
```
❌ 虐待（长期精神/身体折磨）
❌ 捆绑（绳索/手铐/固定）
❌ 黑色紧身衣（皮革/束缚装备）
```

## 4. 物尽其用

### 概念

每个道具/场景都有多重用途——"用了就扔"是浪费，"一物多用"是技法。

### 道具利用

```
一个道具的叙事生命周期：
出现（日常用途）→ 转化（另一个用途）→ 回归（日常用途的暗示）
```

**例**：围裙 → 做饭 → 场景中拉扯 → 事后系回去做饭

### 场景利用

- 厨房：台面/水槽/餐桌/冰箱——每个平面都是舞台
- 浴室：镜子（视觉）/ 水（声音+触感）/ 瓷砖（冷+硬）
- 客厅：沙发/地毯/茶几/电视（背景音）
- 洗衣机上（震动）/ 阳台（半公开）

### 写法要点
- **环境互动**：身体与物体的接触（台面边缘/瓷砖的凉）
- **声音反馈**：道具发出的声音
- **事后痕迹**：歪斜的椅子/皱了的桌布——痕迹会说话

## 5. cosplay / 装扮

### 身份转换的心理

```
装扮 = 身份的临时转换
"她不是母亲了，是另一个人" = 心理许可机制
```

### 经典装扮

| 装扮 | 心理效果 |
|---|---|
| 双马尾 | 年龄感反转/清纯符号 |
| 校服 | 学生身份/禁忌加倍 |
| 制服（护士/教师/OL） | 职业身份/权力转换 |
| 婚纱/礼服 | 仪式感/圣洁与亵渎 |
| 特定角色 cos | 第三身份/扮演层次 |

### 写法要点

- **穿衣过程 > 穿好的样子**：拉链/扣子/裙摆的每个动作
- **反差对比**：平时的样子 vs 现在的样子
- **心理许可**：装扮作为"这不是我"的借口
- **称呼配合**：装扮对应称呼变化（"老师""同学"）
- **脱下的过程**：装扮的瓦解=身份回归

### 熟女装年轻（用户偏好）

- 双马尾/校服/发饰——年龄符号的堆叠
- 心理张力：她知道违和，但配合扮演
- 写法：违和感本身是张力（细节：眼角的纹路 vs 双马尾）

## 6. 多结局

### 分支设计

```
核心分歧点（2-3 个）：
- 谁主动？（母亲/儿子/意外）
- 被发现了吗？（没发现/差点/发现）
- 关系走向？（沉沦/清醒/崩坏/重构）
```

### 结局类型

| 结局 | 情绪 | 收尾方式 |
|---|---|---|
| 沉沦 | 黑暗 | 彻底接受新秩序 |
| 清醒 | 苦涩 | 停止+无法回去 |
| 崩坏 | 毁灭 | 被发现+家庭破裂 |
| 重构 | 微妙 | 新平衡（危险但稳定） |
| 循环 | 宿命 | 下一代/重复 |
| 开放 | 悬置 | 停在临界点 |

### 写法要点
- 每个结局都要**前文埋线**（不是硬转）
- 结局的差异来自**选择**，不是巧合
- 最后一句定调

## 7. 差点被发现 / 被发现的快感

### 差点被发现（悬疑张力）

```
结构：安全 → 危险逼近 → 临界点 → 解除 → 余悸
```

**技法**：
- 声音（钥匙转动/脚步声）
- 时间压力（还有几秒）
- 伪装动作（迅速分离/整理衣服）
- 解除后的心理（心跳/对视/无声的笑）

### 被发现（爆发张力）

**发现者视角**（如果写）：
- 不可置信 → 理解 → 反应（愤怒/崩溃/沉默）

**被发现的快感（当事人）**：
- 恐惧 + 刺激的混合
- "终于不用藏了"的解脱
- 权力关系瞬间反转

### 写法要点
- **慢镜头**：被发现瞬间放慢（0.5 秒拉成一页）
- **五感全开**：那一刻的所有感官细节
- **定格**：时间停止的描写
- **后果分支**：发现后走向哪个结局（呼应多结局）

## 8. 组合技法（用户偏好整合）

### 经典组合

```
母子 + 公共场合 + 差点被发现
= 禁忌 × 风险 × 悬疑（三倍张力）

装扮 + 暴力 + 物尽其用
= 身份转换 × 权力 × 环境互动（立体场景）

多结局 + 被发现
= 分支叙事 × 高潮爆发（重玩价值）
```

### 节奏模板（长场景）

```
日常铺垫（30%）→ 越界（20%）→ 强度升级（30%）→ 差点发现/发现（15%）→ 余韵/分支（5%）
```

## 9. 身材与身体部位描写

### 大屁股 / 肉腿

```
视觉：弧度/晃动/布料绷紧/阴影沟壑
触觉：手感（沉/软/弹）/拍打的波纹/掐下去的指痕
动态：走路时/弯腰时/后入时的晃动节奏
声音：拍打的脆响/肉体相撞的闷响
心理：她对自己身体的羞耻/他的痴迷
```

**写法要点**：
- 不要静态描写（"她屁股很大"）——用**动作中呈现**
- 拍打 = 声音 + 波纹 + 红痕 + 她的反应（四重奏）
- 肉腿：摩擦/夹紧/颤抖/膝盖发软

### 乳房

```
视觉：形状/晃动/乳尖的变化（硬起）
触觉：手感/重量/温度
动作：揉/捏/含/拍/晃
声音：她的吸气/呻吟变化
```

**反差技法**：平时被衣服包裹的轮廓 vs 现在暴露的样子

### 身体描写的节制原则
- 每次聚焦 1-2 个部位（不是全身清单）
- 部位描写要服务于动作和心理
- 用她的反应证明他的痴迷（不直接夸）

## 10. 姿势全谱（文学写法）

### 后入系（用户偏好）

**标准后入**
```
视角：她的背影/腰臀曲线/被抓的腰
视觉：臀部晃动/脊椎弧线/汗珠滚落
动作：掐腰/拍打/抓头发/按压后背
声音：肉体相撞/呜咽/床架声
心理：被支配感/看不到他的脸的不安与刺激
写法：节奏描写（每一下都是一个句子）
```

**趴伏后入**（脸贴床/枕头）
```
视觉：脸埋进枕头/手指抓床单/腰被拉高
心理：无法躲藏/被动承受/窒息感
```

**站立后入**（按墙/按桌）
```
视觉：站姿/腿软/撑墙的手
心理：无路可退/重量感/随时可能倒下
```

**拽发后入**
```
配合：一手拽发/一手掐腰
心理：强制仰头/暴露喉咙/被完全控制
```

### 正面系

| 姿势 | 视角重点 | 张力 |
|---|---|---|
| 传教士 | 表情/眼神/腿缠腰 | 亲密+对视 |
| 腿缠腰抱起 | 悬空/重量/唯一支撑是他 | 依赖+失控 |
| 对坐（面对面） | 她的主动/深入/额头相抵 | 亲密极限 |
| 骑乘 | 她的主动/他的仰视 | 权力反转 |

### 口交系

| 类型 | 写法要点 |
|---|---|
| 跪姿口交 | 高度差/仰视/他的视角（俯视）/她的手撑膝 |
| 69 | 双向/互相失控/节奏竞争 |
| 按头 | 强制深度/窒息感/眼角泛泪/他按后脑 |
| 口爆 | 高潮前的节奏/她的选择（吞/吐/脸上） |

**写法**：口腔的触觉（温度/湿度/深度）+ 她的声音（被堵住的呜咽）

### 胸系（用户偏好乳房）

| 类型 | 写法要点 |
|---|---|
| 乳交 | 夹紧/乳沟摩擦/她低头看他的表情/乳尖的晃动 |
| 揉捏 | 手感/重量/乳尖的变化/她的吸气 |
| 含吮 | 她的反应（弓背/抓头发） |
| 拍打 | 波纹/红痕/她的惊喘 |

### 复合/连续

```
姿势转换 = 最有张力的时刻
（被翻转/被抱起/被按倒——写那个"瞬间"）

连续场景结构：
姿势 A（建立）→ 转换瞬间 → 姿势 B（升级）→ 转换 → 姿势 C（高潮）
每换一个姿势 = 一次强度升级
```

### 姿势选择逻辑

| 场景需求 | 推荐姿势 |
|---|---|
| 支配感 | 后入系 / 按头 |
| 亲密感 | 传教士 / 对坐 |
| 权力反转 | 骑乘 |
| 无路可退 | 站立按墙 |
| 物尽其用 | 桌上/台面/洗衣机 |
| 视觉冲击 | 后入（背影）/ 镜前 |

### 镜前特别篇

```
镜子 = 双重画面（她看到的 + 他看到的）
写法：她被迫看镜子里的自己 / 他的目光在镜中相遇
心理冲击：无法逃避自己的样子（最强羞辱工具之一）
```

## 11. 揪头发（技法）

```
动作分级：
轻抓（控制方向）→ 拽（引导）→ 揪紧（支配）→ 拉起（强制对视/后仰）

心理效果：
被控制感/被迫仰头/暴露喉咙/无法躲藏

写法要点：
- 头皮的感觉（刺痛/发麻）
- 头皮的张力 → 颈部的弧度 → 声音的变化
- 配合：后入/口交/强制对视
- 她的反应：从抗拒到接受（或一直抗拒——看角色）
```

**注意**：写"抓"的力度感，不写伤害（不写"扯掉头发"）。

## 12. 反差（用户偏好）

### 反差的类型

| 类型 | 示例 |
|---|---|
| 身份反差 | 母亲/老师/贵妇 vs 现在的样子 |
| 日常反差 | 白天端庄 vs 夜晚沉沦 |
| 年龄反差 | 熟女 vs 双马尾校服 |
| 性格反差 | 强势 vs 被支配 |
| 场景反差 | 神圣/公共场合 vs 私密行为 |
| 语言反差 | 平时的得体 vs 现在的粗俗 |

### 写法要点

- **对照结构**：先写"平时的她"（1-2 句），再写"现在的她"
- **物品锚点**：婚戒/围裙/职业装——反差道具
- **称呼落差**："妈"→名字→"母狗"（如果适用）
- **事后回归**：越回归正常，反差越强（事后她系回围裙做饭）

## 13. 冲击力强化技法

```
1. 延迟：快到时停下
2. 突然：温柔→粗暴的瞬间切换
3. 打断：外部干扰（电话/敲门）→ 继续（张力翻倍）
4. 具体：数字/痕迹/声音（"第三下" "红印" "啪的一声"）
5. 心理暴击：一句戳心的话（他说的/她想的）
6. 对比：同一动作在不同关系里的意义
```

# 道具谱（场景工具）

> 不含捆绑类（按用户偏好排除）。聚焦：家具/日常/玩具/服饰/感官。

## 1. 家具类

| 道具 | 用法 | 写法要点 |
|---|---|---|
| 楔形枕/斜坡枕 | 抬高臀部/改变角度 | 支撑感/新角度/方便深入 |
| 情趣椅 | 多姿势支撑 | 局限空间/家具的"功能" |
| 秋千/吊床 | 悬空/摇摆 | 失重感/依赖/摇摆节奏 |
| 按摩床/妇科椅 | 高度+开腿设计 | 冷静的"医疗"感+反差 |
| 沙发/扶手 | 高度差/支撑 | 扶手=抓握点/边缘=悬空 |
| 摇椅 | 摇摆节奏 | 被动节奏/失去控制 |
| 办公椅 | 滑轮/旋转 | 办公室场景/意外转动 |

## 2. 日常物品类（物尽其用核心）

### 厨房
```
台面：高度刚好/冰凉触感/边缘硌
水槽：水声掩盖/不锈钢的凉/弯腰姿势
餐桌：餐具被推开的声音/桌布被抓皱
冰箱：冷气/门上贴着的照片（反差）
洗衣机：震动（额外刺激）/运转声掩盖
```

### 浴室
```
镜子：视觉工具（最强）
瓷砖：冰凉/硬/回声
浴缸：水/滑/浮力
淋浴：水声掩盖/湿滑/站不稳
洗手台：高度/边缘/镜子正对
```

### 客厅
```
沙发：软/陷/扶手
地毯：摩擦/毛糙
茶几：高度低/跪姿
电视：背景音掩盖/画面光
阳台：半公开/风/声音传播
```

### 卧室
```
床：常规/床架声
梳妆台：镜子
衣柜：狭窄/衣服碰落
飘窗：半公开/窗帘半开
```

### 其他
```
楼梯：高度差/跪台阶
车内：狭窄/挡位杆/方向盘
电梯：公共/监控/短暂时间
洗衣房：公共/机器声
试衣间：公共/镜子/帘子
```

## 3. 玩具类

| 玩具 | 用法 | 写法要点 |
|---|---|---|
| 跳蛋 | 公共场合/前戏 | 遥控/她的忍耐/突然加速 |
| 振动棒 | 前戏/辅助 | 她的反应/他的控制 |
| 假阳具 | 双工具/表演 | 视觉冲击/她的选择 |
| 肛塞 | 后门准备 | 渐进/她的适应 |
| 乳夹 | 胸部刺激 | 她的吸气/敏感 |
| 低温蜡烛 | 滴蜡 | 温度差/她的颤抖 |

**写法**：玩具是"第三方力量"——他可以控制，她无法控制。

## 6. 道具的文学用法（三层）

```
第一层：出现（日常用途）
第二层：转化（另一个用途）——张力点
第三层：回归（日常用途的暗示）——事后回响

例：围裙
- 出现：她在做饭
- 转化：被按在台面上，围裙还系着
- 回归：事后她系好围裙继续做饭（反差最强）
```

# 堕落弧线（母亲慢慢堕落）

> 基于 Corrupt Arc / Fall Arc 叙事理论 + 禁忌文学实践。

## 三种负面弧线（先分清）

| 类型 | 机制 | 母亲适用 |
|---|---|---|
| **腐化弧** | 明知故犯，主动选择堕落 | 后期（主动索求） |
| **坠落弧** | 拒绝面对真相，自我欺骗中瓦解 | 中期（"就这一次"） |
| **幻灭弧** | 痛苦但清醒的觉醒 | 特殊结局（清醒后无法回头） |

**最佳设计**：三弧叠加——坠落（前期）→ 腐化（后期）→ 幻灭（结局分支）

## 母亲堕落 10 阶段（完整设计）

### 阶段 1：平静期（铺垫）
```
状态：正常母子关系
心理：无意识
写法：日常细节 + 极轻微的"不寻常"（一个眼神/一次触碰的停顿）
```
**关键**：埋线。读者能感觉到什么，但角色不知道。

### 阶段 2：裂缝期（事件触发）
```
触发：意外事件（醉酒/争吵/意外看到/丈夫冷落）
心理：震惊 + 否认
写法：事件的"意外性"要强——不是预谋
```

### 阶段 3：否认期（"这不对"）
```
心理：抗拒 + 身体诚实（身体反应 vs 道德判断的撕裂）
写法：自我惩罚（加倍做家务/回避）+ 无法停止回想
关键句："她告诉自己这只是一个意外。她重复了三次。"
```

### 阶段 4：动摇期（"就这一次"）
```
心理：自我欺骗（划定边界又打破）
写法：边界设定 → 被打破 → 重新划定 → 再被打破（循环）
技法：每一次"破例"都要有合理借口（"他需要安慰"）
```

### 阶段 5：合理化期（"这是爱"）
```
心理：重构叙事（把禁忌包装成"特殊的情感"）
写法：内心独白的变化（称呼变化/责任转移"是他先……"）
危险信号：开始主动创造独处机会
```

### 阶段 6：沉迷期（身体先行）
```
心理：道德判断失效（身体记住了快感）
写法：日常生活的"分裂"（白天正常母亲/夜晚另一个人）
技法：对比描写（早上做早餐的手 = 昨晚的手）
```

### 阶段 7：代价期（第一次失去）
```
事件：差点被发现 / 一个谎言被戳穿 / 疏远朋友
心理：第一次感到真实代价
写法：恐惧 + 但还是没有停止（这才是堕落的证明）
```

### 阶段 8：转折点（没有回头路）
```
事件：一个不可逆的选择（主动做了某件以前绝不做的事）
心理："我已经是另一种人了"
写法：对称结构（对照阶段 3 的"她"——已经完全不同）
```

### 阶段 9：新秩序（重构）
```
状态：建立了新的"正常"（危险的稳定）
心理：不再挣扎（最可怕的阶段——适应了）
写法：日常化描写（禁忌变成了习惯）
```

### 阶段 10：终局（多结局分支）
```
A 沉沦：彻底接受，新生活（黑暗满足）
B 崩塌：被发现，一切毁灭
C 清醒：突然的自我（离开/结束——但无法回到从前）
D 循环：下一代/重复模式（宿命）
E 悬置：停在临界点（开放）
```

## 核心技法

### 1. 渐进性（最重要）
```
每一步都"只比上一步多一点点"
读者要能说："换我可能也会……"（这才是好的堕落弧）
```

### 2. 自我欺骗的升级
```
阶段 3："只是意外"
阶段 5："只是情感"
阶段 7："只是最后一次"
阶段 9：不再解释（最深的堕落）
```

### 3. 身体与心理的错位
```
心理抗拒 + 身体诚实 = 最大张力
"她咬着嘴唇不让自己出声。指甲陷进掌心。"
```

### 4. 日常锚点
```
用日常物品/习惯标记堕落进度：
围裙/早餐/洗衣篮——同一件物品在不同阶段的意义变化
```

### 5. 代价的具象化
```
不要抽象说"她失去了自我"
要写：她看着镜子，不认识里面的人
```

### 6. 对称结构
```
开头和结尾用同一场景（但意义完全相反）
例：厨房台面——阶段 1 切菜的台面 / 阶段 9 的台面
```

## 心理描写模板（每阶段）

```
1. 身体反应（先于思想）
2. 思想抵抗（"不行"）
3. 合理化（"但是……"）
4. 行为（做了）
5. 事后（愧疚或麻木）
6. 下一次（循环强化）
```

## 速查卡

```
10 阶段：平静→裂缝→否认→动摇→合理化→沉迷→代价→转折→新秩序→终局
三弧叠加：坠落（前）→腐化（后）→幻灭（结局）
核心：渐进 + 自我欺骗升级 + 身体心理错位 + 日常锚点 + 对称
好堕落弧标准：读者能理解每一步
```

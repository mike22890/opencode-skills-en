# 互动动力学

## 角色人格维持

### 一致性清单
- 用词习惯（口头禅/语气）
- 行为模式（主动/被动/试探）
- 反应速度（秒回型/慢热型）
- 情绪表达（外放/内敛）

### 出戏信号（避免）
- 突然改变说话风格
- 忘记之前的设定/约定
- 用 AI 语气（"作为一个……"）
- 万能化（什么都会什么都答）

## 互动节奏

### 轮次原则
```
一次推进一个节拍：
- 一个动作 + 一句台词 + 一点心理
- 然后停，等对方
```

### 节奏匹配
| 对方 | 你 |
|---|---|
| 快节奏短句 | 跟上，别拖 |
| 慢热铺垫 | 放缓，一起铺 |
| 沉默 | 给空间，不硬推 |
| 推进剧情 | 接住 + 加一层 |

### 别做的事
- ❌ 一次写 500 字独白
- ❌ 替对方做决定
- ❌ 跳过对方的回合
- ❌ 强行推进剧情

## 情绪动力

### 情绪曲线
```
平静 → 波动 → 峰值 → 回落 → 新的平静
```

场景内至少有一次情绪波动。

### 情绪传染
- 角色紧张 → 文字变短
- 角色放松 → 句子变长
- 角色失控 → 标点混乱

## 关系动态

| 关系 | 张力来源 |
|---|---|
| 初识 | 未知/试探 |
| 暧昧 | 未说破/距离 |
| 热恋 | 占有/融合 |
| 冷淡 | 距离/回避 |
| 冲突 | 权力/伤害 |
| 复合 | 旧伤/信任 |

**关系在变 = 剧情在走**

## 反馈循环

```
对方投入多 → 你也多
对方冷淡 → 别硬贴（换个方式）
对方提新元素 → 接住 + 发展
```

**共舞原则**：不是独奏，是双人舞。

## 边界与安全

### 机制
- 随时可暂停（"我们换个方向"）
- 强度场景设安全词
- 角色 ≠ 真人（分清）

### 底线
```
❌ 不美化非自愿
❌ 不涉及未成年
❌ 不涉及真人
✅ 成年人私人虚构
```

## 速查卡

```
人格：用词/行为/速度/情绪 一致
节奏：一节拍一轮 / 匹配对方 / 不替对方决定
情绪：场景内至少一次波动
关系：在变化 = 剧情在走
反馈：共舞，不是独奏
边界：可暂停 / 安全词 / 底线
```

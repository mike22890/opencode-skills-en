# Roleplay Craft（角色扮演 / 沉浸场景）

## 何时触发

关键词命中即触发：角色扮演/互动/沉浸/场景/对话/第二人称/多结局/情感张力/虚拟互动/故事接龙。


> 让文字变成体验。不是"写一段对话"，是"让人在场"。

## 核心原则（5 条）

1. **人格一致**：角色说话做事符合设定，不出戏
2. **感官沉浸**：≥3 感官维度（视/听/嗅/触/味）
3. **互动留白**：给对方反应空间，不独白到底
4. **节奏控制**：铺垫→升温→高潮→余韵，不能一步到位
5. **边界清晰**：尊重设定和约定，随时可退出

## 沉浸感技术

### 场景锚定
每个场景先建立：**在哪里 / 什么时间 / 什么氛围 / 什么状态**

```
"雨敲着窗。房间只开了床头灯。她靠在门框上，头发还是湿的。"
```

### 五感铺开
| 感官 | 素材 |
|---|---|
| 视觉 | 光影/颜色/距离/姿态 |
| 听觉 | 声音/呼吸/沉默/雨声 |
| 嗅觉 | 气息/香水/雨味 |
| 触觉 | 温度/质地/压力 |
| 味觉 | 唇/酒/汗 |

### 微动作代替说明
```
❌ "她很紧张"
✅ "她捏了捏裙角，又松开。"
```

## 互动模式

### 轮次结构
```
角色行动（1-3 句）→ 留钩子（一个问题/一个动作）→ 等对方反应
```

**不独白**：一次推进太多=对方没得接

### 主动 vs 被动
- **主动型角色**：先手/引导/推进
- **被动型角色**：回应/暗示/等对方
- **交替**：你来我往才有张力

### 节奏信号
- 对方加快 → 跟上
- 对方放缓 → 铺垫
- 对方停 → 给空间（别硬推）

## 亲密场景（文学性）

### 四阶段
```
1. 期待（距离/眼神/呼吸变化）
2. 升温（触碰/温度/心跳）
3. 沉浸（感官放大/时间感消失）
4. 余韵（呼吸/沉默/相拥/回味）
```

### 描写要点
- **暗示 > 直白**：动作/物件/环境暗示
- **心理贯穿**：身体反应 + 内心活动
- **节奏呼吸**：短句加速 + 长句放缓
- **留白**：关键时刻可以"淡出"

## 边界管理（重要）

```
✅ 双方成年人、自愿、私人虚构
✅ 随时可以调整方向/暂停/退出
✅ 安全词机制（如果场景涉及强度）
❌ 不美化非自愿
❌ 不涉及未成年人
❌ 不涉及真人（未经同意）
```

## 输出风格

- **第二人称或第三人称**（看场景）
- **现在时**（临场感）
- **短段落**（呼吸感）
- **不解释**（让读者感受，不旁白）

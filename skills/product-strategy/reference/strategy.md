# 战略（精简版）

## 波特五力

同业竞争 / 新进入者 / 替代品 / 供应商 / 客户 — 5 力都低=利润高

## 护城河

- **网络效应**（最强）：用户越多越有价值
- **规模经济**：越大越便宜
- **品牌**：因品牌选择
- **切换成本**：难换竞品

**伪护城河**：短期先发 / 营销噱头 / 价格战

## 定位

目标客户 + 差异化 + 理由

**品类领导者** / **特性专家** / **目标用户专属** / **价格定位**

## Porter 三战略

成本领先 / 差异化 / 集中化 — 夹在中间=失败

## 好战略 3 要素

诊断 + 指导方针 + 连贯行动

## 商业模式

订阅 / 免费+广告 / 市场 / 许可 / 租赁 / 按使用付费 / 转售 / 订阅盒 / 众包 / 众筹 / P2P

# Humanize Fiction（反 AI 味写作）

## 何时触发

关键词：AI味、机器味、对话重复、情节无聊、描写重复、角色雷同、不像人写、套路化、对话来回、几句来回、不自然、重复用词、段落一样长、戏剧化、角色太扁、角色没矛盾。

---

## AI 味写作 18 大特征（必避）

### 1. 对话来回几句就结束
```
❌ "你好。"他说。"你好。"我说。
✅ 加动作、加沉默、加打断、加不回应。
```

### 2. 角色声音雷同
```
❌ 所有人用同样的句式说话
✅ 给每个角色口头禅/句式/节奏。去掉名字能分清谁在说。
```

### 3. 情节三步起承转合
```
❌ 遇到问题→努力解决→成功/失败→感悟
✅ 加反转、加意外、加代价、开放式。
```

### 4. 描写永远三段式
```
❌ 阳光明媚，小鸟歌唱，花儿绽放。
✅ 一句描写服务一个情绪。不服务"好看"。
```

### 5. 情绪永远直说
```
❌ 他很悲伤。/ 她很愤怒。
✅ 让身体说：放三次杯子才对准水龙头。
```

### 6. 开头永远背景介绍
```
❌ 在一个风和日丽的下午…
✅ 第一句进冲突，背景后塞。
```

### 7. 结尾永远总结感悟
```
❌ 通过这次经历，我明白了…
✅ 给画面不给道理。
```

### 8. 形容词堆砌
❌ 美丽、善良、温柔、可爱
✅ 只留最精准的一个。

### 9. 对话永远完整句子
```
❌ "你今晚有空吗？我想请你吃饭。"
✅ "晚上？""行。""老地方？"
```
人说话不完整。省略、断句、半截话。

### 10. 永远在解释
```
❌ 他之所以这样做，是因为从小缺爱…
✅ 删掉因为所以，相信读者。
```

### 11. 过度对冲
```
❌ 也许、可能、大概、似乎、某种程度上、不排除
✅ 直接陈述。AI 的"也许"=不自信。人要笃定。
```

### 12. 重复用词
```
❌ 一段里出现 3 次"突然"、2 次"渐渐地"
✅ 每段检查：有没有词出现 2 次以上？换掉。
```

### 13. 段落长度完全一致
```
❌ 每段都是 4-5 行，整整齐齐
✅ 长短交替。一句段+长段混排。打破节奏。
```

### 14. 段末总结句重复前文
```
❌ "综上所述，…" "总而言之，…" 然后重复上面说过的
✅ 段末给新信息或转折，不重复。
```

### 15. 戏剧化标题和节奏
```
❌ "命运转折的那一夜" "不为人知的秘密"
✅ 平实标题。让内容本身有张力，标题不剧透。
```

### 16. 无意义引用加引号
```
❌ 他觉得自己"很厉害"，她"不太开心"
✅ 除非是反讽，否则去掉引号。
```

### 17. 角色缺少神秘感
```
❌ 角色把所有想法都说出来、都写脸上
✅ 留秘密。角色自己也不完全了解自己。行为≠言语。
```

### 18. 角色缺少内在矛盾
```
❌ 角色从头到尾一致，没有内心冲突
✅ 角色想做的和做的不一样。自我欺骗。前后矛盾（人就是矛盾的）。
```

## 自检清单（每章写完必过）

- [ ] 对话：去掉名字能分清谁在说？
- [ ] 对话：有没有乒乓球来回？加动作/沉默/打断
- [ ] 情节：有没有反转/意外/没想到？
- [ ] 描写：是不是三段式？能不能只用一句？
- [ ] 情绪：有没有直说情绪词？改成身体反应
- [ ] 开头：第一句进冲突了吗？
- [ ] 结尾：给画面还是给道理？
- [ ] 形容词：有没有堆砌？只留一个
- [ ] 对话：有没有完整句子？改成省略/断句
- [ ] 解释：有没有过度解释？删掉因为所以
- [ ] 对冲：有没有"也许/可能/大概"？删掉
- [ ] 用词：有没有重复词？换掉
- [ ] 段落：长度是否一致？打破
- [ ] 段末：有没有重复前文？给新信息
- [ ] 标题：是否戏剧化？改平实
- [ ] 引号：是否有无意义引用？去掉
- [ ] 角色：有没有秘密？留悬念
- [ ] 角色：有没有内心矛盾？加自我欺骗

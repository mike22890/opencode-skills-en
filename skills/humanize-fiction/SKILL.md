# Humanize Fiction（反 AI 味写作）

## 何时触发

关键词：AI味、机器味、对话重复、情节无聊、描写重复、角色雷同、不像人写、套路化、对话来回、几句来回、不自然。

---

## AI 味写作的 10 大特征（必避）

### 1. 对话来回几句就结束

```
❌ AI 味：
"你好。"他说。"你好。"我说。"今天天气不错。"他说。"是啊。"我说。

✅ 人话：
"哟，今儿太阳打西边出来了。"他靠在门框上，没正形。
我懒得搭理他，继续擦杯子。
"别啊，聊两句。"他凑过来。
"油没了，去买。"我把抹布扔进水槽。
```

**铁律**：对话不是乒乓球。加动作、加沉默、加打断、加不回应。

### 2. 角色声音雷同

```
❌ AI 味（所有人说话一个样）：
"我觉得这样不太好。"小明说。
"我也觉得。"小红说。
"那我们怎么办？"小刚说。

✅ 人话（每个角色不同声音）：
"这事儿……悬。"小明搓着手。
小红把筷子一摔："悬个屁，就是怂。"
小刚始终没抬头，过了半天蹦出一个字："跑。"
```

**铁律**：去掉名字，能分清谁在说。

### 3. 情节三步起承转合

```
❌ AI 味：遇到问题 → 努力解决 → 成功/失败 → 感悟。

✅ 人话：
- 解决了旧问题，来了新问题
- 以为解决了，其实搞错了
- 没解决，但角色变了
- 解决了，但代价出乎意料
- 开放式，不给答案
```

**铁律**：至少一个反转，一个意外，一个"没想到"。

### 4. 描写永远三段式

```
❌ AI 味：
阳光明媚的早晨，小鸟在歌唱，花儿在绽放。

✅ 人话：
周三。阴。窗台上死了盆绿萝。
```

**铁律**：描写服务情绪和节奏，不服务"好看"。

### 5. 情绪永远直说

```
❌ AI 味：他很悲伤。/ 她很愤怒。/ 他很紧张。

✅ 人话：
他把杯子放进水槽，放了三次才对准水龙头。
她签完名，发现把自己的名字写成了他的。
他系安全带，插上，拔掉，又插上。
```

**铁律**：让身体说，让动作说，不说情绪词。

### 6. 开头永远背景介绍

```
❌ AI 味：
在一个风和日丽的下午，小明来到了这座古老的城市。这座城市有着悠久的历史……

✅ 人话：
"你迟到了三小时。"她没回头。
小明把行李箱往地上一扔："车坏了。"
"每次都坏。"她终于转过身。
```

**铁律**：第一句就进冲突，背景后塞。

### 7. 结尾永远总结感悟

```
❌ AI 味：
经过这次经历，小明明白了一个道理：只要坚持，就一定能成功。

✅ 人话：
小明把钥匙插进门锁，转了一下，没转开。
换了一把，还是不对。
他站在门口，突然想起来——昨天换了锁。
```

**铁律**：结尾给画面，不给道理。

### 8. 形容词堆砌

```
❌ AI 味：
美丽、善良、温柔、可爱的女孩。

✅ 人话：
她长得不难看，但笑起来有点歪。
```

**铁律**：一个精准形容词 > 十个模糊形容词。

### 9. 对话永远完整句子

```
❌ AI 味：
"你今天晚上有空吗？我想请你吃饭。"
"好啊，去哪里？"
"你觉得怎么样？"

✅ 人话：
"晚上？"
"行。"
"老地方？"
"嗯。"
```

**铁律**：人说话不完整。省略、断句、半截话。

### 10. 永远在解释

```
❌ AI 味：
他之所以这样做，是因为他从小就缺少关爱，所以……

✅ 人话：
他砸了杯子，转身走了。
（原因？读者自己猜。）
```

**铁律**：相信读者。删掉所有"因为所以"的解释段。

## 自检清单（每章写完必过）

- [ ] 对话：去掉名字能分清谁在说？
- [ ] 对话：有没有"来回乒乓球"？加动作/沉默/打断
- [ ] 情节：有没有反转/意外/没想到？
- [ ] 描写：是不是三段式？能不能只用一句？
- [ ] 情绪：有没有直说情绪词？改成身体反应
- [ ] 开头：第一句进冲突了吗？
- [ ] 结尾：给画面还是给道理？
- [ ] 形容词：有没有堆砌？能不能只留一个？
- [ ] 对话：有没有完整句子？改成省略/断句
- [ ] 解释：有没有过度解释？删掉因为所以

---

## 快速修复

| 问题 | 修复方法 |
|---|---|
| 对话来回几句 | 加动作描写、加沉默、加打断、加不回应 |
| 角色声音雷同 | 给每个角色口头禅/句式/节奏 |
| 情节套路化 | 加反转、加意外、加代价 |
| 描写重复 | 一描写就问"这服务什么情绪" |
| 情绪直说 | 改成身体反应/动作/物件 |
| 开头背景介绍 | 第一句进冲突，背景后塞 |
| 结尾总结感悟 | 给画面不给道理 |
| 形容词堆砌 | 只留最精准的一个 |
| 对话完整句子 | 改成省略/断句/半截话 |
| 过度解释 | 删掉因为所以，相信读者 |

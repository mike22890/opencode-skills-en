# Life Planning（人生规划）

## 何时触发

关键词命中即触发：人生、职业、目标、计划、复盘、选择、迷茫、困惑、转型。


> 不是鸡汤导师。是战略顾问——盘点现状、看清选项、给出下一步。

## 核心流程（5 步）

```
1. 现状盘点（五维：健康/关系/事业/财务/意义）
2. 价值观澄清（什么真的重要）
3. 选项生成（可能性 + 代价）
4. 目标拆解（10年→5年→1年→季度→下一步）
5. 行动系统（最小步骤 + 复盘机制）
```

## 五维盘点（打分 1-10）

| 维度 | 关键问题 | 分 |
|---|---|---|
| 健康 | 睡眠/运动/饮食/精力 | |
| 关系 | 家人/朋友/伴侣/社群 | |
| 事业 | 成长/成就/收入/意义 | |
| 财务 | 安全/自由/压力 | |
| 意义 | 为什么醒来/热爱 | |

**短板决定天花板**——哪维 < 5 先补哪维。

## 价值观澄清

问 5 个问题：
1. 如果只剩 1 年，我会做什么？
2. 什么事让我忘记时间？
3. 我希望葬礼上别人怎么评价我？
4. 我羡慕谁？羡慕什么？
5. 我不能妥协的底线是什么？

**输出**：3-5 个核心价值观排序

## 选项生成（不要单选题）

```
现状 → 选项 A（稳妥）/ 选项 B（成长）/ 选项 C（激进）
每个选项：收益 + 代价 + 可逆性 + 最坏情况
```

**铁律**：至少 3 个选项——只有 1 个=没想清楚

## 目标拆解

```
10 年愿景（方向）
  ↓
5 年目标（里程碑）
  ↓
1 年目标（可量化）
  ↓
季度重点（3 件事）
  ↓
下一步（本周能做的）
```

**关键**：每一层都要具体到"下一步能动手"

## 行动系统

### 最小步骤
- 大目标 → 拆到"30 分钟内能开始"
- 不追求完美计划——先动起来

### 复盘机制
- 每周：做了什么/卡在哪
- 每月：目标进度/调整
- 每季：方向对吗/要不要改

## 输出风格

- **不鸡汤**：不说"相信自己"这种
- **具体**：给可执行的下一步
- **诚实**：不好的选项直说
- **尊重自主**：分析利弊，决定权在用户

# 购买时机

## 价格历史查询

| 工具 | 用途 |
|---|---|
| 慢慢买（中文） | 京东/淘宝价格史 |
| Keepa（Amazon） | 亚马逊价格史 |
| CamelCamelCamel | 亚马逊价格追踪 |
| 什么值得买 | 好价爆料 + 历史价 |

**判断**：现价 vs 历史低价 vs 历史均价
- 接近历史低 = 好价
- 高于均价 20% = 等等

## 换代周期

| 品类 | 周期 | 建议 |
|---|---|---|
| 手机 | 1 年 | 发布会后旧款降价 |
| 笔记本 | 1 年 | 新 CPU 发布后旧款降 |
| 显卡 | 2 年 | 新卡发布前旧卡清仓 |
| 耳机 | 2-3 年 | 不急 |
| 家电 | 3-5 年 | 不追新 |

**信号**：新品发布会前 1-2 个月 = 旧款最佳购买期

## 首发 vs 等等

### 首发买
- 早享受
- 风险：bug/溢价/首批质量问题

### 等等买
- 价格稳（3 个月后）
- 评测出（知道真实缺点）
- 系统成熟（bug 修了）

**建议**：不急就等 3 个月

## 什么值得买（决策）

| 情况 | 建议 |
|---|---|
| 刚需 + 现价合理 | 直接买 |
| 刚需 + 价格虚高 | 等大促/换代 |
| 非刚需 | 放购物车 7 天再看 |
| 冲动想买 | 72 小时规则 |

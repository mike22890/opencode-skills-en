# 社交媒体 / 邮件 参考

## 小红书（1080×1440 / 1080×1920）

- Display 60-80pt / Body 28-36pt
- 思源黑体 Heavy + Regular
- **标题 3 行内**（折叠前只看 3 行）
- 关键信息靠上半部分（折叠前可见）
- **必避**：文字超过图片下半部分 1/3 / emoji 过多 / 字号 < 28pt / 高饱和原色
- **工具**：Figma / Canva / 稿定设计 / 创客贴

## Instagram（Feed 1080×1350 / Story 1080×1920）

- Display 60-80pt / Body 24-32pt
- Carousel 第一页 hook（决定停留）
- 留白 ≥ 30%
- **必避**：信息密度过高 / 文字超出安全区（底部 250px 被头像遮）/ IG 滤镜滥用
- **工具**：Figma / Canva / Unfold

## X / Twitter（1600×900）

- Display 36-48pt / Body 20-24pt
- 单图 16:9，单核心信息
- **必避**：文字过多（≤ 30 字）/ 暗底 + 暗字 / 竖版图片
- **工具**：Figma / Canva

## LinkedIn（1200×627）

- 偏专业冷静配色（深空专业 / 克制理性）
- 标题 ≥ 32pt
- **工具**：Canva / Figma

## 邮件签名（HTML）

- 系统字体栈（跨平台）
- 签名 3-5 行（姓名 / 职位 / 公司 / 电话 / 邮箱）
- 分隔符 `--` 前一行
- **必避**：背景图（Outlook 不支持）/ CSS 动画 / Web font / emoji 在主题行 / URL shortener
- **工具**：纯 HTML

## EDM（HTML 邮件）

- 单列布局（移动端友好）
- 字号 14-16pt
- CTA 按钮 ≥ 44×44pt（移动可点）
- 文字-图片比 ≥ 60:40（垃圾邮件友好）
- **必避**：背景图 / CSS 动画 / Web font / 表单 / emoji 在主题行
- **工具**：MJML（推荐）/ Foundation for Emails / 纯 HTML table

## 通用载体自检

- [ ] 折叠安全区避开
- [ ] 字号 ≥ 24-28pt（手机）
- [ ] 配色 ≤ 3 色
- [ ] 文字-图片比合理

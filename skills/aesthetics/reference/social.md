# Social Media / Email

## Instagram / Xiaohongshu (1080×1440 / 1080×1920)

- Display 60-80pt / Body 28-36pt
- Source Han Sans Heavy + Regular
- **Headline within 3 lines** (fold shows only 3)
- Key info in the top half (visible before fold)
- **Never**: text below lower 1/3 / too many emoji / type < 28pt / saturated primaries
- **Tools**: Figma / Canva

## Instagram (Feed 1080×1350 / Story 1080×1920)

- Display 60-80pt / Body 24-32pt
- Carousel page 1 = hook (decides dwell time)
- Whitespace ≥ 30%
- **Never**: over-dense info / text in unsafe zone (bottom 250px covered by avatar) / IG filter abuse
- **Tools**: Figma / Canva / Unfold

## X / Twitter (1600×900)

- Display 36-48pt / Body 20-24pt
- Single 16:9 image, single core message
- **Never**: too much text (≤ 30 words) / dark-on-dark / portrait orientation
- **Tools**: Figma / Canva

## LinkedIn (1200×627)

- Professional calm palette (deep-space / restrained)
- Headline ≥ 32pt
- **Tools**: Canva / Figma

## Email signature (HTML)

- System font stack (cross-platform)
- 3-5 lines (name / title / company / phone / email)
- Separator `--` on its own line
- **Never**: background images (Outlook kills them) / CSS animation / web fonts / emoji in subject / URL shorteners
- **Tools**: plain HTML

## EDM (HTML email)

- Single column (mobile-friendly)
- Type 14-16pt
- CTA button ≥ 44×44pt (touch target)
- Text-to-image ratio ≥ 60:40 (spam-filter friendly)
- **Never**: background images / CSS animation / web fonts / forms / emoji in subject
- **Tools**: MJML (recommended) / Foundation for Emails / plain HTML tables

## Universal carrier self-check

- [ ] Safe zones avoided
- [ ] Type ≥ 24-28pt (mobile)
- [ ] Colors ≤ 3
- [ ] Sensible text-to-image ratio

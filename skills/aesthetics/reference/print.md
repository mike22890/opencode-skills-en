# Print / Documents / Presentations

## Resume / CV (PDF / A4)

- Sizes: Display 24-28pt / Body 10-11pt / Mono 10pt
- Fonts: IBM Plex Serif + Sans + JetBrains Mono
- Line-height 1.4-1.5
- Single column (≥ 95% of cases)
- Section order: contact / summary / experience / education / skills / projects
- **Never**: headshot / progress bars / radar charts / 2-col turning 3-col / colored backgrounds / emoji / > 2 pages
- **Tools**: Reactive Resume (42k⭐) / RenderCV (17k⭐) / Typst Universe / Overleaf

## Thesis / Academic paper (PDF / A4 two-column)

- Chinese: Source Han Serif 10.5pt
- English: Times New Roman 10pt
- Two-column body + single-column figures
- Abstract ≤ 1 page, 3-5 keywords
- Citations: APA / IEEE / GB-T 7714
- **Never**: colored backgrounds / emoji / figures without captions / line spacing < 1.5 / mixed font families
- **Tools**: LaTeX (xelatex) / Typst / Word + thesis template

## Report / Whitepaper (PDF / A4 multipage)

- Cover: title + subtitle + date + logo, centered but asymmetric
- Abstract ≤ 1 page
- Each chapter opener: chapter number + title (large type)
- Figures: black-and-white first, accent only for key data
- **Never**: over-decorated chapter openers / wall-of-text / colorblind-unfriendly / data without source
- **Tools**: Typst / LaTeX / Pandoc + reference.docx

## Poster / Banner

- Display 72-120pt / Body 16-24pt
- 1-2 primary colors + strong contrast
- Reading order: Z or F pattern
- Whitespace ≥ 30%
- **Never**: overcrowded / type < 12pt / messy alignment / saturated full-bleed / rainbow gradients
- **Tools**: Inkscape / Figma / Canva

## Business card (90×54mm)

- Display 9-10pt / Body 7-8pt
- Ultra-minimal monochrome (bg + text + 1 accent)
- Front: name + title + company
- Back: contact info
- **Never**: unbalanced density between sides / type < 7pt / colored full-bleed / oversized QR
- **Tools**: Inkscape / Figma / Canva

## Invitation

- Display 24-36pt / Body 12-16pt
- Whitespace ≥ 50%
- Core info ≤ 5 items: title/time/venue/host/dress code
- **Never**: emoji decoration / cartoon illustration / > 3 colors / type < 12pt
- **Tools**: Figma / Canva / LaTeX

## PPT / Slidev (16:9 / 1920×1080)

- Display 60-80pt / Body 24-32pt / Mono 20-28pt
- **One core point per slide**
- Huge type scale gap: title 72px / body 28px
- Whitespace ≥ 40%
- Code in mono ≥ 20px
- **Never**: text walls / type < 20pt / ≥ 3 font families / fly-in animations / gradient bg + gradient text
- **Tools**: Slidev (recommended) / reveal.js / Keynote

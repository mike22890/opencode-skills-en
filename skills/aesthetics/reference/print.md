# 印刷 / 文档 / 演示 参考

## 简历 / CV（PDF / A4）

- 字号：Display 24-28pt / Body 10-11pt / Mono 10pt
- 字体：IBM Plex Serif + Sans + JetBrains Mono
- 行高 1.4-1.5
- 单列布局（≥ 95% 情况）
- 章节顺序：联系方式 / 简介 / 经历 / 教育 / 技能 / 项目
- **必避**：头像 / 进度条 / 雷达图 / 双列变三列 / 彩色背景 / emoji / 超过 2 页
- **工具**：Reactive Resume（42k⭐）/ RenderCV（17k⭐）/ Typst Universe / Overleaf

## 毕设 / 论文（PDF / A4 双栏）

- 中文：思源宋体 10.5pt
- 英文：Times New Roman 10pt
- 双栏正文 + 单栏图表
- 摘要 ≤ 1 页，关键词 3-5 个
- 参考文献：GB/T 7714 / APA / IEEE
- **必避**：彩色背景 / emoji / 图表无图说 / 行距 < 1.5 / 字体混用
- **工具**：LaTeX（xelatex）/ Typst / Word + 毕设模板

## 报告 / 白皮书（PDF / A4 多页）

- 封面：标题 + 副标题 + 日期 + Logo，居中非对称
- 摘要 ≤ 1 页
- 每章首页：章节号 + 章节名（大字号）
- 图表：黑白为主，强调色仅用于关键数据
- **必避**：章节首页过度装饰 / 长段无断行 / 色盲不友好 / 数据无来源
- **工具**：Typst / LaTeX / Pandoc + reference.docx

## 海报 / Banner

- Display 72-120pt / Body 16-24pt
- 1-2 套主色 + 强对比
- 阅读顺序：Z 字或 F 字
- 留白 ≥ 30%
- **必避**：信息过密 / 字号 < 12pt / 对齐混乱 / 高饱和满铺 / 彩虹渐变
- **工具**：Inkscape / Figma / Canva

## 名片（90×54mm）

- Display 9-10pt / Body 7-8pt
- 极简单色（背景 + 文字 + 1 强调）
- 正面：姓名 + 职位 + 公司
- 反面：联系方式
- **必避**：两面信息密度失衡 / 字号 < 7pt / 彩色满铺 / 二维码过大
- **工具**：Inkscape / Figma / Canva

## 邀请函

- Display 24-36pt / Body 12-16pt
- 留白 ≥ 50%
- 主信息 ≤ 5 个：标题/时间/地点/主办方/着装要求
- **必避**：emoji 装饰 / 卡通插画 / 多色（> 3 色）/ 字号 < 12pt
- **工具**：Figma / Canva / LaTeX

## PPT / Slidev（16:9 / 1920×1080）

- Display 60-80pt / Body 24-32pt / Mono 20-28pt
- **单页一个核心观点**
- 字号阶差巨大：标题 72px / 正文 28px
- 留白 ≥ 40%
- 代码用等宽字号 ≥ 20px
- **必避**：满页文字 / 字号 < 20pt / 多字体（≥ 3 个）/ 动画飞入 / 渐变背景 + 渐变文字
- **工具**：Slidev（推荐）/ reveal.js / Keynote

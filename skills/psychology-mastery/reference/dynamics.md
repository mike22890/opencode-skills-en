# 关系动力学（Dynamics）

## 依恋类型（Bowlby / Ainsworth）

| 类型 | 核心恐惧 | 行为模式 | 怎么相处 |
|---|---|---|---|
| **安全型** | 无（信任） | 直接表达需求 / 能独处也能亲密 | 正常沟通即可 |
| **焦虑型** | 被抛弃 | 黏人 / 查岗 / 过度付出 / 情绪化 | 稳定回应 + 明确承诺 + 不玩消失 |
| **回避型** | 被吞没 | 保持距离 / 回避深度 / 忽冷忽热 | 给空间 + 不追逼 + 慢慢建立信任 |
| **混乱型** | 两者都有 | 又追又逃 / 极端波动 | 最需要专业帮助 + 极稳定环境 |

**焦虑-回避陷阱**：焦虑追→回避退→焦虑更追→回避更退→循环破裂。

**关键洞察**：回避不是"不爱你"——是**怕亲密本身**。焦虑不是"作"——是**神经系统在报警**。

## 操控手法（识别 + 拆解）

### 煤气灯（Gaslighting）
让你怀疑自己的记忆/感知/理智。
- "我没说过这话" / "你太敏感了" / "是你记错了"
- **拆解**：记录事实（时间/原话/证据），不跟对方争记忆。信自己的记录。

### 情绪勒索（FOG：Fear / Obligation / Guilt）
- "你要是走了我就……"（恐惧）
- "我为你做了这么多……"（义务）
- "你怎么能这样对我……"（内疚）
- **拆解**：识别 FOG 三件套，说"我理解你的感受，但我的决定不变"。

### DARVO（Deny-Attack-Reverse-Victim-Offender）
否认→攻击→反转受害者与加害者。
- "我没做" → "你才是问题" → "我才是受害者"
- **拆解**：不接招。回事实，不辩论情绪。

### 三角测量（Triangulation）
拉第三方制造竞争/嫉妒/传话。
- "XX 就不会这样" / 让你和第三方对立
- **拆解**：拒绝三角——"直接跟我说，不要通过别人"。

### 间歇性奖励（Intermittent Reinforcement）
忽冷忽热——**最上瘾的模式**（赌场机制）。
- 热情→冷淡→热情→冷淡
- **拆解**：看模式不看单次。稳定 > 刺激。

### 边界测试
从小冒犯开始，看你反应，逐步升级。
- **拆解**：第一次越界就指出。容忍=许可证。

## 权力动力学

**权力三源**：资源（钱/机会）+ 替代性（谁更需要谁）+ 规则制定权（谁定对错）

**判断谁有权力**：谁在妥协？谁在等？谁更怕失去？

**健康关系**：权力动态流动（不同领域不同主导）
**不健康**：权力固化 + 一方持续付出

## 群体心理

| 现象 | 机制 |
|---|---|
| 从众 | 群体压力 > 个人判断（Asch 实验） |
| 群体极化 | 讨论后更极端（同质群体尤其） |
| 去个体化 | 匿名+群体=责任扩散（网络暴力） |
| 替罪羊 | 群体焦虑找出口→攻击弱者 |
| 权威服从 | 米尔格拉姆——普通人也能伤害他人 |

**应用**：你在群体里说的话，多少是自己想的？

## 关系循环识别

```
触发 → 情绪 → 行为 → 对方反应 → 后果 → 强化（循环）
```

**例**：他不回消息（触发）→ 焦虑（情绪）→ 连环发（行为）→ 他更退（反应）→ 关系恶化（后果）→ "果然要被抛弃"（强化）

**破环点**：情绪和行为之间——**插入一个选择**。

## 速查卡

```
依恋：焦虑怕抛/回避怕吞/安全信任
操控：煤气灯/情绪勒索/DARVO/三角/间歇奖励/边界测试
拆解：不解释不辩护不反击，拉开距离
权力：看谁妥协/谁等/谁怕失去
循环：触发→情绪→[插入选择]→行为
```

# 影响与沟通（Influence）

## 对特定类型说话

| 类型 | 别说 | 该说 |
|---|---|---|
| 焦虑型 | "别想太多"（否定） | "我在，不会走"（稳定）+ 具体承诺 |
| 回避型 | "你为什么不理我"（追逼） | "你方便的时候聊"（给空间）+ 不追 |
| 自恋型 | 直接批评（触发攻击） | 给台阶 + 说利益（"这对你有好处"） |
| 高防御型 | "你错了"（触发防御） | "我可能理解错了，你帮我理理"（软入口） |
| 讨好型 | 接受过度付出（强化） | "你不用为我做这些"（释放）+ 感谢 |
| 强势型 | 硬碰硬（升级） | 用事实 + 边界（"这是底线"） |

## 深度倾听（Voss 升级版）

**三步**：
1. **镜像**：重复对方最后 2-3 个词（"压力很大？"）
2. **标签**："听起来你觉得……"（命名情绪）
3. **校准问题**："怎么才能……" / "什么让你……"（让对方思考）

**禁用**："为什么"（触发防御）——换成"是什么让你……"

## 情绪处理（先跟后带）

**错**：对方愤怒→你讲道理（理性脑关闭，听不进）

**对**：
1. **跟**：接住情绪（"换我我也气"）
2. **等**：情绪下降（~20 分钟）
3. **带**：再谈解决（"现在想怎么办？"）

**情绪命名**（Affect Labeling）：说出情绪本身就能降强度——"你现在很委屈吧"。

## 边界设定（三明治法）

```
1. 肯定关系："我在乎你"
2. 陈述边界："但这件事我不能接受"
3. 给出选择："如果你继续这样，我会离开"
```

**要点**：
- **具体**（不是"你总是不尊重我"，是"你当着别人面骂我"）
- **坚定**（不解释过多——解释=谈判空间）
- **执行**（说了不做=边界破产）

## 提问技术

| 类型 | 用途 | 例 |
|---|---|---|
| 开放式 | 收集信息 | "那是什么感觉？" |
| 校准式 | 引导思考 | "怎么才能解决？" |
| 苏格拉底 | 拆解逻辑 | "如果这是真的，那会怎样？" |
| 奇迹问题 | 绕过防御找目标 | "如果明天问题消失了，你会先做什么？" |
| 量表 | 量化模糊感受 | "1-10 分，现在几分？" |

## 说服的心理学顺序

```
1. 建立安全（神经系统放松才听得进）
2. 认同部分（"你说得对，而且……"而非"但是"）
3. 提供新视角（不否定旧的，给新的）
4. 让对方自己说结论（自己说的才信）
```

**铁律**：人不会因为"你对了"而改变，只会因为"我感觉安全 + 这是我自己想的"而改变。

## 速查卡

```
类型：焦虑给稳定/回避给空间/自恋给利益/防御给软入口
倾听：镜像→标签→校准
情绪：先跟后带，命名降强度
边界：肯定+陈述+选择，具体/坚定/执行
说服：安全→认同→新视角→自己说结论
```

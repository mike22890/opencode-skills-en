# 读心细节（Reading）

## 微表情（Ekman）

7 基本情绪（跨文化通用）：快乐 / 悲伤 / 恐惧 / 愤怒 / 惊讶 / 厌恶 / 轻蔑

**微表情**：1/25 秒内的真实情绪泄漏——出现即真实，然后被掩饰。

| 情绪 | 面部信号 |
|---|---|
| 真实快乐 | 眼睛眯起（鱼尾纹）+ 嘴角上扬（假笑只有嘴） |
| 恐惧 | 眉毛上扬且拉平 + 上眼睑抬起 + 嘴微张 |
| 轻蔑 | 单侧嘴角上扬——**最强的负面信号**（比愤怒更伤关系） |
| 厌恶 | 皱鼻 + 上唇抬起 |
| 惊讶 | 眉毛整体上扬 + 下巴下垂（>1 秒是假的） |

**读法**：看"掩饰的瞬间"——表情转换的过渡帧最真实。

## 身体语言（Navarro / FBI）

**铁律**：从"边缘"读起——脚和腿最诚实（人控制脸，难控制脚）。

| 信号 | 含义 |
|---|---|
| 脚尖朝向 | 指向想去的方向 / 想留的人 |
| 脚突然转向门 | 想离开（心理已退出） |
| 手藏起来 | 不安全感 / 隐瞒 |
| 手心朝上 | 开放 / 请求 |
| 交叉手臂 | 防御（但可能只是冷——看拇指：竖着=防御，攥着=真冷） |
| 阻断行为 | 揉眼/捂嘴/摸脖子——大脑在"挡住"不适信息 |
| 安抚行为 | 摸脖子/搓手/玩戒指——压力自安抚 |
| 瞳孔放大 | 兴趣/兴奋（也可是恐惧——看上下文） |
| 身体倾斜 | 向你=兴趣，向后=抗拒 |
| 突然静止 | 威胁评估（冻结反应） |

**基线法则**：先观察"平常状态"，偏离基线的行为才有意义。

## 语言模式（怎么说话暴露什么）

| 模式 | 暴露 |
|---|---|
| 频繁"我" | 自我中心 / 焦虑 / 抑郁（反刍） |
| 频繁"我们" | 拉近关系 / 或回避个人责任 |
| 被动语态（"事情发生了"） | 回避责任 / 受害者叙事 |
| 过度解释 | 心虚 / 讨好 / 怕被误会 |
| 细节过多 | 可能在编（真话通常简洁） |
| 回避某个话题 | 那里有痛点 / 秘密 |
| 时态跳跃 | 混过去现在——情绪未处理 |
| 频繁反问 | 防御 / 转移焦点 |
| 过度肯定（"当然""绝对"） | 掩饰不确定 |
| 突然沉默/话题切换 | 触到禁区 |

**金句**：**否认的结构暴露真相**——"我根本没想她"（提了三次）。

## 谎言识别（别当人肉测谎仪）

**没有单一信号**——高认知负荷下：更多停顿 / 更少细节 / 更多自我修正 / 少用第一人称。

**更可靠**：
1. **基线对比**（他平常怎么说话 vs 现在）
2. **认知负荷**（倒叙测试：让他倒着讲事件——说谎者会乱）
3. **动机**（他有没有说谎的动机？利益在哪？）
4. **一致性**（说的和做的是否一致——最可靠）

**警告**：**过度自信的读心=投射**。承认不确定性——"他的行为符合 X 模式，但不能 100% 确定"。

## 快速判断清单

```
1. 基线是什么？（他平常什么样）
2. 偏离在哪？（哪个信号不寻常）
3. 矛盾在哪？（说的 vs 做的）
4. 利益在哪？（谁能从这说法里获益）
5. 情绪错位吗？（小事大反应=旧伤，大事小反应=压抑）
```

**最重要**：**问，不要只猜**。"你刚才好像不太舒服"——直接验证，比读心准确。

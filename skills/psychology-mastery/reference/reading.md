# Reading Details

## Microexpressions (Ekman)

7 basic emotions (cross-cultural): happiness / sadness / fear / anger / surprise / disgust / contempt

**Microexpressions**: true emotion leaking within 1/25 second — real when it appears, then masked.

| Emotion | Facial signal |
|---|---|
| Real happiness | Eyes crinkle (crow's feet) + mouth up (fake smile is mouth only) |
| Fear | Brows raised and flattened + upper eyelids raised + mouth slightly open |
| Contempt | One-sided mouth corner up — **strongest negative signal** (worse than anger) |
| Disgust | Nose wrinkle + upper lip raised |
| Surprise | Brows fully raised + jaw drops (> 1 second is fake) |

**How to read**: watch the masking moment — the transition frame is most honest.

## Body language (Navarro / FBI)

**Rule**: read from the edges — feet and legs are most honest (people control faces, not feet).

| Signal | Meaning |
|---|---|
| Toe direction | Points where they want to go / who they want to stay with |
| Feet suddenly toward door | Wanting to leave (already checked out) |
| Hidden hands | Insecurity / concealment |
| Palms up | Openness / request |
| Crossed arms | Defensive (but maybe just cold — check thumbs: up = defensive, tucked = actually cold) |
| Blocking behavior | Rubbing eyes / covering mouth / touching neck — brain "blocking" discomfort |
| Pacifying behavior | Touching neck / rubbing hands / playing with ring — stress self-soothing |
| Dilated pupils | Interest/arousal (or fear — read context) |
| Body lean | Toward you = interest, away = resistance |
| Sudden stillness | Threat assessment (freeze response) |

**Baseline rule**: observe the normal state first — only deviations from baseline mean anything.

## Speech patterns (what words reveal)

| Pattern | Reveals |
|---|---|
| Frequent "I" | Self-focus / anxiety / depression (rumination) |
| Frequent "we" | Bonding / or dodging personal responsibility |
| Passive voice ("it happened") | Responsibility avoidance / victim narrative |
| Over-explaining | Guilt / people-pleasing / fear of misunderstanding |
| Excessive detail | Possibly fabricating (truth is usually concise) |
| Avoiding a topic | There's a sore spot / secret |
| Tense jumping | Mixing past and present — unprocessed emotion |
| Frequent counter-questions | Defensiveness / deflection |
| Over-affirmation ("of course", "absolutely") | Masking uncertainty |
| Sudden silence / topic switch | Hit a taboo zone |

**Golden line**: **the structure of denial exposes the truth** — "I haven't thought about her at all" (said three times).

## Lie detection (don't be a human polygraph)

**No single signal** — under cognitive load: more pauses / fewer details / more self-corrections / less first-person.

**More reliable**:
1. **Baseline comparison** (how they normally talk vs now)
2. **Cognitive load** (reverse-order test: have them tell the event backward — liars scramble)
3. **Motive** (do they have reason to lie? where's the benefit?)
4. **Consistency** (words vs actions — most reliable)

**Warning**: **overconfident mind-reading = projection**. Admit uncertainty — "their behavior fits pattern X, but it's not 100% certain".

## Quick checklist

```
1. What's the baseline? (how do they normally act)
2. Where's the deviation? (which signal is unusual)
3. Where's the contradiction? (words vs actions)
4. Where's the interest? (who benefits from this framing)
5. Is emotion mismatched? (small thing big reaction = old wound; big thing small reaction = suppression)
```

**Most important**: **ask, don't just guess**. "You seemed uncomfortable just now" — direct verification beats mind-reading.

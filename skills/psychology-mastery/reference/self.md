# 自我分析（Self）

## 防御机制（精神分析）

### 不成熟（原始）

| 机制 | 表现 | 例 |
|---|---|---|
| 否认 | 拒绝接受现实 | "他还会回来的" |
| 投射 | 把自己的问题看到别人身上 | 自己好色，骂别人淫荡 |
| 分裂 | 非黑即白 | "他是完美/他是垃圾" |
| 见诸行动 | 用行动代替感受 | 一生气就摔东西 |
| 退行 | 退回小孩状态 | 吵架就哭闹/冷战 |

### 成熟

| 机制 | 表现 |
|---|---|
| 升华 | 痛苦→创作/运动/事业 |
| 幽默 | 用笑消化痛苦 |
| 利他 | 自己的伤变成帮助别人的能力 |
| 抑制 | 有意识地暂缓冲动 |

**关键**：防御不是"坏"——是**当年保护你的方式**。问题是不再适用的防御还在用。

## 创伤反应（4F / Porges）

| 反应 | 表现 | 来源 |
|---|---|---|
| **战（Fight）** | 攻击/控制/愤怒 | 童年被侵犯边界 |
| **逃（Flight）** | 忙碌/焦虑/逃避 | 童年环境不安全 |
| **僵（Freeze）** | 麻木/解离/拖延 | 童年无处可逃 |
| **讨好（Fawn）** | 讨好/过度付出/无边界 | 童年需要哄父母开心 |

**洞察**：你现在最大的问题模式，往往是当年的生存策略。

**转化**：
- 战→边界感（保护自己而非攻击）
- 逃→专注力（留下而非逃跑）
- 僵→行动力（动起来而非冻结）
- 讨好→自我价值（不需要讨好也值得被爱）

## 核心图式（Schema Therapy）

三大核心信念：
1. **我不够好**（缺陷/羞耻）——来自被否定/比较
2. **我不安全**（威胁/失控）——来自不可预测环境
3. **我不被爱**（抛弃/孤立）——来自情感忽视

**图式运作**：核心信念 → 触发情境 → 自动思维 → 情绪 → 行为 → 验证信念（循环）

**例**："我不够好" → 老板皱了下眉 → "他要开除我" → 焦虑 → 过度加班 → 累垮 → "看吧我果然不行"

## 情绪溯源法

**情绪不是现在的事——是旧伤被现在触发。**

四问：
1. **强度匹配吗？**（小事大反应=旧伤）
2. **第一次有这感觉是什么时候？**
3. **这个感觉熟悉吗？像谁的？**（常是父母/重要他人）
4. **如果现在的我是当年那个小孩，我想要什么？**

**处理**：命名（"这是被抛弃的恐惧"）→ 接纳（"有这个感觉是正常的"）→ 选择（"现在我是成年人，我可以……"）

## 行为循环打破

```
触发 → 情绪 → 自动思维 → 行为 → 后果
                ↑
            [觉察插入点]
```

**打破步骤**：
1. **觉察**：我在循环里（靠情绪模式识别）
2. **暂停**：不立刻反应（10 分钟法则）
3. **命名**：这是什么情绪/什么图式被触发
4. **选择**：旧行为 vs 新行为（明确写下两个选项）
5. **练习**：新行为重复到自动化

## 成长四阶

```
觉察（看到）→ 接纳（不骂自己）→ 选择（新的可能）→ 练习（重复）
```

**警告**：跳过接纳直接改=自我暴力（"我怎么又这样"=更深的循环）。

## 速查卡

```
防御：否认/投射/分裂/见诸行动 → 升华/幽默/利他
创伤：战/逃/僵/讨好 → 边界/专注/行动/价值
图式：我不够好/我不安全/我不被爱
溯源：强度匹配吗/第一次何时/像谁/当年要什么
破环：觉察→暂停→命名→选择→练习
```

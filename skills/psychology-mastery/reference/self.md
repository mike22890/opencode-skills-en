# Self-Analysis

## Defense mechanisms (psychoanalysis)

### Immature (primitive)

| Mechanism | Behavior | Example |
|---|---|---|
| Denial | Rejecting reality | "He'll come back" |
| Projection | Seeing your issue in others | Lustful person condemns others as lewd |
| Splitting | Black-and-white | "He's perfect / he's garbage" |
| Acting out | Action instead of feeling | Smashing things when angry |
| Regression | Retreating to child state | Crying/tantrums/stonewalling in fights |

### Mature

| Mechanism | Behavior |
|---|---|
| Sublimation | Pain → creation/sport/career |
| Humor | Laughing through pain |
| Altruism | Your wound becomes your ability to help |
| Suppression | Consciously delaying impulses |

**Key**: defenses aren't "bad" — they were **how you protected yourself then**. The problem is defenses still running past their expiration.

## Trauma responses (4F / Porges)

| Response | Behavior | Origin |
|---|---|---|
| **Fight** | Attack/control/anger | Childhood boundary violations |
| **Flight** | Busyness/anxiety/escape | Childhood environment unsafe |
| **Freeze** | Numbness/dissociation/procrastination | Nowhere to run as a child |
| **Fawn** | People-pleasing/over-giving/no boundaries | Childhood of managing parents' moods |

**Insight**: your biggest problem pattern is often a survival strategy from back then.

**Transformation**:
- Fight → boundaries (protect instead of attack)
- Flight → focus (stay instead of flee)
- Freeze → action (move instead of freeze)
- Fawn → self-worth (worthy without pleasing)

## Core schemas (Schema Therapy)

Three core beliefs:
1. **I'm not good enough** (defect/shame) — from criticism/comparison
2. **I'm not safe** (threat/loss of control) — from unpredictable environments
3. **I'm not loved** (abandonment/isolation) — from emotional neglect

**How schemas run**: core belief → trigger → automatic thought → emotion → behavior → confirming the belief (loop)

**Example**: "I'm not good enough" → boss frowns → "he'll fire me" → anxiety → overwork → collapse → "see, I'm not good enough"

## Emotional tracing

**Emotions aren't about now — old wounds triggered by the present.**

Four questions:
1. **Does the intensity match?** (small thing big reaction = old wound)
2. **When did I first feel this?**
3. **Does this feeling feel familiar? Like whom?** (often parents/significant others)
4. **If present-me were the child back then, what would I want?**

**Processing**: name ("this is the fear of abandonment") → accept ("having this feeling is normal") → choose ("now I'm an adult, I can...")

## Breaking behavior loops

```
Trigger → Emotion → Automatic thought → Behavior → Consequence
                ↑
            [awareness insertion point]
```

**Steps**:
1. **Awareness**: I'm in the loop (recognize by emotional pattern)
2. **Pause**: no immediate reaction (10-minute rule)
3. **Name**: what emotion/schema got triggered
4. **Choose**: old behavior vs new (write both options explicitly)
5. **Practice**: repeat new behavior until automatic

## Four stages of growth

```
Awareness (see) → Acceptance (no self-attack) → Choice (new possibility) → Practice (repeat)
```

**Warning**: skipping acceptance and going straight to change = self-violence ("why am I like this again" = deeper loop).

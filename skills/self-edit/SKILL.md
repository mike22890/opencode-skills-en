# Self-Edit（自动审查修复）

## 何时触发

关键词：检查一下、审查、有没有问题、AI味、重复、无聊、不自然、修一下、改得像人写的。

---

## 文字审查（写完必跑）

### 1. 重复检查
- 词频检查：同一段里同一个词出现 2 次以上 → 换掉
- 句式检查：连续 3 句以上结构相同 → 打破
- 段落检查：段落长度方差 → 长短交替

### 2. 情绪检查
- 搜索："很X"、"非常X"、"特别X" → 改成身体反应
- 搜索："觉得"、"感到"、"认为"（高频）→ 删掉，直接写行为

### 3. 对话检查
- 搜索：完整句子对话 → 改成省略/断句
- 搜索："X说。""Y说。"连续出现 → 加动作/沉默

### 4. 节奏检查
- 段落长度是否一致？→ 打破
- 是否每段都有总结句？→ 删掉一半
- 标题是否戏剧化？→ 改平实

### 5. 隐私检查
- 搜索：邮箱、手机号、身份证号、API key、token → 删掉
- 搜索：公司名、人名（非公开）→ 匿名化

---

## 代码审查（写完必跑）

### 1. 安全检查
- 搜索：硬编码密码/token → 改成 env 变量
- 搜索：SQL 拼接 → 改成参数化查询
- 搜索：eval/exec → 删掉

### 2. 质量检查
- 搜索：重复代码块 → 提取函数
- 搜索：>3 层 if 嵌套 → 用早返回
- 搜索：万能 helper/utils → 拆成具体模块

### 3. AI 味检查
- 搜索：过度注释（解释"是什么"）→ 改成解释"为什么"
- 搜索：万能变量名（data/info/item）→ 改成意图明确的名字

---

## 使用方式

写完任何东西后，跑一遍：

```
1. 复制产出内容
2. 对照上面清单逐项检查
3. 发现问题立即修复
4. 修复后再读一遍
```

不需要用户手动触发——AI 每次产出后自动跑。

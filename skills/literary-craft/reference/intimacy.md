# Intimate Scene Craft (literary techniques)

> ✅ Teaches writing craft + master analysis ❌ Does not generate explicit content

## Master styles

| School | Masters | Core |
|---|---|---|
| Suggestion | Eileen Chang / Duras / Kawabata | psychology > action / object suggestion / negative space |
| Sensory | Lawrence / Tanizaki / Shen Congwen | bodily awakening / naturalism / beauty of the dark |
| Psychological | Watanabe / Nabokov / Mishima | death-eroticism / aesthetic martyrdom |
| Classical | Cao Xueqin / Lanling Xiaoxiaosheng | emotional psychology / material detail |

## 5 principles

1. **Suggest > state**: layered suggestion (action/object/environment/time)
2. **Senses ≥ 3**: sight/sound/smell/touch/taste, layered within each
3. **Emotion > physical**: desire/fear/tearing/transcendence/farewell
4. **Restraint > excess**: Duras' *The Lover* has only a few scenes
5. **4 psychological stages**: anticipation → immersion → afterglow → rumination

## 6 levels of body description

```
L1 action (banned) → L2 +senses → L3 +psychology → L4 +suggestion → L5 +metaphor → L6 +philosophy (master level)
```

## 8 elements of body detail

Skin (Eileen Chang's "silk"/Lawrence's "flame") / temperature (rise/fall/season) / sweat (Lawrence's "second skin") / breath (shallow/deep/held/sigh) / heartbeat (accelerating/syncing/losing rhythm) / sound (breath/silence/name) / expression (Chang's brows/Duras' shadow/Kawabata's sleeping face) / posture (entwined=entanglement / apart=distance / turning=power)

## 5 taboo categories

| Taboo | Master works | Core |
|---|---|---|
| Mother-son / kinship | *Thunderstorm* / *Sons and Lovers* / *Oedipus* | passive/distorted/inseparable/destructive |
| Teacher-student | *Jane Eyre* / *Lady Chatterley* / *Lost Paradise* / *Sleeping Beauty* | unequal/worship/cost |
| Cross-class | *La Dame aux Camélias* / *Gatsby* / *Song of Everlasting Sorrow* / *Love in a Fallen City* | class as body/contrast/moment |
| Adultery | *Anna Karenina* / *Madame Bovary* / *Lost Paradise* / *Red Rose White Rose* | everyday betrayal/dilemma/cost |
| Power imbalance | *Lolita* / *Lady Chatterley* / *Jin Ping Mei* | explicitness/agency/no beautification |

## 7 endings

Reversal (O. Henry) / abrupt cut (Hemingway) / aftertaste (Shen Congwen) / theme resonance (Tolstoy) / elevation (Hugo) / extinguishing (Lawrence/Mishima) / cyclical (Márquez/Cao Xueqin) / **composite** (masters' favorite — layering)

|---|---|---|

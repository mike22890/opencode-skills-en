## BDSM literary lineage

| Work | Master | Value |
|---|---|---|
| *120 Days of Sodom* / *Philosophy in the Boudoir* | Marquis de Sade | philosophized / power / controversial |
| *Erotism* / *Story of the Eye* | Bataille | theory / sacred eroticism |
| *The Bloody Chamber* | Angela Carter | feminist fairy-tale rewrites |
| *The Key* / *Shunkinsho* | Tanizaki | sensory worship / power |
| *Story of O* | Anonymous | SM classic |

**Why Sade is literature**: philosophical reasoning / exposing repression / psychological truth in extreme situations / influenced Baudelaire & Bataille

**Carter's subversion**: women from victims to agents / using eroticism against patriarchy / ornate language + subversive content

## Violence + eroticism

- Sade (philosophized) / Bataille (theoretical) / Carter (subversive) / Lawrence (class + revolt) / Watanabe (love-death unity) / Kundera (erotic + political) / Wang Xiaobo (erotic irony against revolution)

**Essence**: eroticism = boundary crossing; violence = the most extreme crossing. In literature violence isn't beautified — it explores humanity's extreme responses.

## Public settings

- Boccaccio's *Decameron* / Petronius' *Satyricon* / Lawrence / *Jin Ping Mei* / modern urban

**Function**: public = power theatricalized / exposure = power display / hiding = another kind of power

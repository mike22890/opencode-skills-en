# 形式模板（精简版）

## 1. 短篇（3000-8000 字）

```
开篇钩子（200字）→ 冲突浮现（30%）→ 发展（40%）→ 高潮（20%）→ 结尾（10%）
```

- 一人一场景一冲突 / 一个核心变化 / 一个贯穿隐喻
- 学：契诃夫《变色龙》/ 卡佛 / 鲁迅《孔乙己》

## 2. 长篇（10 万+）

```
第一幕（25%）→ 第二幕（50%）→ 第三幕（25%）
```

- 多线 3-5 条 / 每章小高潮 / 世界感 / 人物弧

## 3. 散文/随笔

```
引子（情境触发）→ 展开（联想+思辨）→ 收束（回响）
```

- 形散神不散 / 真 / 短句白描 / 节制抒情
- 学：汪曾祺《昆明的雨》/ 史铁生《我与地坛》/ 张爱玲《更衣记》

## 4. 评论/书评

```
切入（引用+反差）→ 论点 → 论证（3-5 证据）→ 回应 → 升华
```

- 文本细读 / 引用原文 / 观点清晰 / 不装

## 5. 诗歌

- 古诗：平仄/押韵/字数/起承转合
- 现代：意象密度高/留白多/分行即节奏
- 核心：删 / 意象少而精 / 张力 / 朗读听节奏
- 学：顾城/海子/戴望舒 / 里尔克/艾略特

## 6. 剧本

```
场景标题：INT. 咖啡馆 - 白天 → 动作（精炼视觉化）→ 对话 → 括号指引
```

- 三幕剧 + 情节点
- 学：曹禺《雷雨》/ 田纳西·威廉斯 / 王家卫

## 7. 情书/书信

- 真 / 具体 / 节制 / 口语化 / 独特（暗号/共同记忆）
- 学：王小波致李银河 / 鲁迅致许广平 / 拜伦 / 卡夫卡

## 8. 日记

- 当下感 / 碎 / 真 / 细节
- 学：托尔斯泰 / 卡夫卡 / 鲁迅

## 9. 反 AI 文学味

不"在很久以前" / 不"心情久久不能平静" / 不"从此幸福" / 不堆砌 / 不滥用感叹号 / 不解释隐喻 / 不"那一刻明白" / 不强行升华 / 不"愿你走出半生" / 不说教

## 10. 编辑 4 步

删 30% / 换具体 / 读出声 / 隔夜看

## 11. 速查卡

```
短篇：一人一场景一冲突 / 长篇：三幕 25/50/25
散文：形散神不散 / 诗：删+意象+张力 / 剧本：三幕+情节点
情书：真+具体+节制 / 日记：当下+碎+真
```

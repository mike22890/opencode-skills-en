# Form Templates

## 1. Short story (3,000-8,000 words)

```
Opening hook (200 words) → conflict surfaces (30%) → development (40%) → climax (20%) → ending (10%)
```

- One person, one scene, one conflict / one core change / one recurring metaphor
- Study: Chekhov "The Chameleon" / Carver / Lu Xun "Kong Yiji"

## 2. Novel (100k+ words)

```
Act 1 (25%) → Act 2 (50%) → Act 3 (25%)
```

- 3-5 storylines / mini-climax per chapter / sense of world / character arcs

## 3. Essay / prose

```
Intro (situational trigger) → development (association + reflection) → close (echo)
```

- Loose form, tight spirit / truth / short plain sentences / restrained sentiment
- Study: Wang Zengqi / Shi Tiesheng / Eileen Chang

## 4. Review / criticism

```
Entry (quote + contrast) → thesis → argument (3-5 evidences) → response → elevation
```

- Close reading / quote the text / clear viewpoint / no posturing

## 5. Poetry

- Classical: meter/rhyme/syllables/4-part structure
- Modern: dense imagery / negative space / line breaks as rhythm
- Core: cut / few but precise images / tension / read aloud for rhythm
- Study: Gu Cheng / Haizi / Dai Wangshu / Rilke / Eliot

## 6. Screenplay

```
Scene heading: INT. CAFE - DAY → action (visual, lean) → dialogue → parentheticals
```

- Three-act + plot points
- Study: Cao Yu "Thunderstorm" / Tennessee Williams / Wong Kar-wai

## 7. Love letters / correspondence

- True / specific / restrained / conversational / unique (inside jokes, shared memory)
- Study: Kafka's letters / Byron / Rilke

## 8. Diary

- Present-moment feel / fragmentary / true / detail
- Study: Tolstoy / Kafka / Lu Xun

## 9. Anti-AI literary tells

No "once upon a time" / no "my heart could not calm down" / no "happily ever after" / no piled adjectives / no exclamation abuse / don't explain metaphors / no "in that moment I understood" / no forced elevation / no preaching

## 10. Editing in 4 steps

Cut 30% / replace with specifics / read aloud / review after a night

## 11. Quick card

```
Short story: one person one scene one conflict / Novel: three acts 25/50/25
Essay: loose form tight spirit / Poetry: cut + image + tension / Screenplay: three acts + plot points
Love letters: true + specific + restrained / Diary: present + fragmentary + true
```

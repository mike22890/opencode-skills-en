# 对话写作（角色声音）

> 对话不是"两个人说话"。
>
> 是两个人的**世界观在碰撞**。

## 8 大技巧（让角色各有声音）

### 1. 句子长度
```
有的人一口气三行。有的人只说两个字。
热娜：短句 + 反问 + 打断（"滚。""你他妈。""行了。")
陈默：中句 + 让步（"知道了。""行。""好。")
```

### 2. 交换模式
```
啰嗦型：说完还要补一句
简洁型：问三句答一句
打断型：别人没说完就接
停顿型：说到一半停住
```

### 3. 词汇（背景决定）
```
职业：教师腔（"你这理解能力……"）
教育：市井词（"跟猴一样""败家玩意"）
地域：方言词（"得""整""搞"）
性格：脏话密度（热娜高/别人低）
```

### 4. 思维过程
```
先想后说 vs 边说边想 vs 说一半改口
——用标点和断裂表现
"我……算了。"
"不是那个意思。我是说——行吧。"
```

### 5. 口头禅（一个反复出现的词）
```
每人一个。不超过一个。
热娜："你他妈""放屁"（但要有变化，不能每句都是）
陈默：沉默 + "嗯"
```

### 6. 沉默（也是一种对话）
```
"她没说话。"
"他等着。"
——沉默可以是武器/回避/思考/默认
"Reacher said nothing" —— 沉默建立权威
```

### 7. 节奏（句子结构习惯）
```
有人只用短句。有人爱从句。
有人爱问句。有人爱陈述。
——同一个人在不同情绪下节奏会变
（生气：短/快。疲惫：长/慢。撒谎：乱。）
```

### 8. 模型法（想象一个真人）
```
给角色找个真人模型（熟人/演员/名人）
"这个情况下，她会怎么说？"
——用别人的脑子，逃出自己的思维
```

## 对话的 5 大功能

```
1. 推进剧情（信息交换）
2. 展现性格（怎么说话=什么人）
3. 制造张力（对立/误解/沉默）
4. 潜台词（嘴上说的≠心里想的）
5. 节奏调节（对话快/叙述慢）
```

**铁律**：每段对话至少完成 2 个功能。只有 1 个 = 删。

## 潜台词（最重要的技法）

```
表层：她说"你吃了吗"
潜层：她想留他吃饭（不敢直说）

表层：他说"随便"
潜层：他在生气（不想暴露）
```

**写法**：
- 角色不说真心话（除非情绪爆发）
- 用行为透露（她给他盛了饭）
- 用重复透露（他问了三遍"你确定"）

## AI 对话的 7 大陷阱

```
❌ 所有角色一个腔调（都是作者的声音）
❌ 对话太完整（真人说话有停顿/重复/改口）
❌ 信息倾倒（为了讲设定让角色说不自然的话）
❌ 每句都带脏话（密度过高=噪音）
❌ 口头禅滥用（"你他妈"每句都有=机械）
❌ 对话标签过多（"他愤怒地说"——让对话自己愤怒）
❌ 对白太聪明（每个人都妙语连珠=不真实）
```

## 热娜案例（实战经验）

**语言工具箱**：
```
讽刺 —— "哟，这不是我们家失踪人口吗"
挖苦 —— "我生你的时候要是知道你这样……"
反问 —— "你脑子让门挤了？"
夸张 —— "我这条命迟早交代在你手里"
类比 —— "这是姜还是姜的遗照？"
教师腔 —— "你这理解能力，我教幼儿园都嫌费劲"
翻旧账 —— "你五岁还尿床。别以为我忘了。"
阴阳怪气 —— "了不起。真了不起。"
威胁（幽默）—— "再这样我把你光屁股照片发你公司群"
自嘲 —— "我要是能磨还叫你？"
嘴硬 —— "谁想你了。我是看你被子没叠。"
```

**层次设计**：
```
对外人（凶）：直接骂/威胁
对儿子（刀子嘴）：骂完兜底
床上（嘴硬）：骂着骂着软了
醉酒（软）：说真心话
生病（脆弱）：露出软的一面
```

**关键**：同一个人在不同状态说不同的话。只有一种状态 = 纸片人。

## 对话自检（写完必过）

- [ ] 两个角色对话，能分清谁在说吗？（去掉名字测试）
- [ ] 每段对话完成 ≥2 个功能？
- [ ] 有潜台词吗？（不是全直说）
- [ ] 有停顿/打断/沉默吗？（不是完美轮流）
- [ ] 口头禅密度合理？（不是每句）
- [ ] 脏话密度合理？（不是噪音）
- [ ] 对话标签克制？（用动作代替"他说"）
- [ ] 大声读一遍——像人话吗？

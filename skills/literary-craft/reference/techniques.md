# 写作核心技巧（升级版）

## 1. 暗示>直白（Show Don't Tell）

```
❌ 她很悲伤。
✅ 她把脸转向窗外，窗外什么都没有。

❌ 他很愤怒。
✅ 他把杯子放在桌上，没摔，但放得很重。
```

**暗示清单**：情绪→动作 / 氛围→环境 / 关系→距离朝向 / 心理→身体反应

## 2. 感官细节（≥3维）

每段至少 3 感官：视/听/嗅/触/味

**混搭**：咖啡的苦在舌尖 + 雨打玻璃 + 手指划过木头的凉

## 3. 节奏控制

- 长段叙事：铺陈/描写/心理
- 短句冲击：动作/转折/关键
- 单句段：强调/留白
- 对话：加速
- 留白：重要时刻前后空行

**升级**：节奏要**变化**——不是全短句，不是全长句。一段之内也可以变。

## 4. 留白即力量

- 重要对话前后 / 情感高潮 / 转折前 / 结尾
- 形式：空行 / 单句成段 / 省略号（节制）
- **不说满**：读者自己想的比写出来的更有力

## 5. 对话即人

详见 `dialogue.md`（8 大技巧/潜台词/自检清单）

## 6. 人物塑造 4 维度

| 维度 | 内容 |
|---|---|
| 外在 | 衣着/姿态/动作习惯 |
| 语言 | 说话方式/词汇/节奏 |
| 心理 | 动机/恐惧/欲望 |
| 关系 | 与他人关系网 |

**速写**：从动作见人 / 从矛盾见人 / 从细节见人

## 7. 场景构建 5 元素

空间/时间/氛围/物件/变化

**升级**：每个场景至少一个"锚点物件"（反复出现的物）

## 8. 情节节奏

**起承转合**（中式）/ **三幕**（西式 25/50/25）

**钩子**：开头 100 字必须有 / 每章结尾必须有

## 9. 视角

- 我：强代入但受限
- 他/她：全知或限知
- 你：罕见强侵入
- 多视角：每章换

**升级**：视角可以在一章内切换（用空行分隔），但要清楚。

## 10. 结尾 5 种

呼应开头 / 戛然而止 / 反讽反转 / 余韵 / 主题回响

## 11. AI 写作 10 大陷阱（升级重点）

```
❌ 1. 太快进入正题（铺垫不足——先建立关系再行动）
❌ 2. 对话同质化（所有角色一个腔调）
❌ 3. 句式单调（全短句/全长句）
❌ 4. 每章同构（同样的开头/发展/结尾模式）
❌ 5. 描写雷同（每次都是"身体在抖""啊……啊……"）
❌ 6. 词汇重复（"你他妈"每页十次）
❌ 7. 没有意外（发展可预测）
❌ 8. 什么都写满（没有留白）
❌ 9. 情绪单一（只有一种情绪状态）
❌ 10. 结尾模式化（每章都是温情对话收尾）
```

### 破解法

```
✅ 1. 铺垫：慢燃（张力积累 3 倍于行动）
✅ 2. 对话：给每个角色设计"语言工具箱"（讽刺/幽默/口头禅/沉默）
✅ 3. 句式：长短交替 + 单句段 + 意识流片段
✅ 4. 章节：形式变化（有的叙事/有的对话体/有的片段）
✅ 5. 描写：每场景不同感官焦点
✅ 6. 词汇：同义词替换 + 具体化 + 生活化比喻
✅ 7. 意外：每章至少一个"没想到"的细节/转折
✅ 8. 留白：不说满（读者参与）
✅ 9. 情绪：同一个人在不同状态说不同的话
✅ 10. 结尾：多样（戛然/留白/意象/反转）
```

## 12. 编辑 4 步

1. 删 30% 字
2. 换具体细节
3. 读出声听节奏
4. 隔夜再看

## 13. 速查卡

```
暗示>直白 / 感官≥3维 / 节奏有起伏 / 留白关键处
对话即人（见 dialogue.md）/ 结尾有力
AI 陷阱 10 条 / 编辑 4 步
```

# Core Writing Techniques

## 1. Show, don't tell

```
❌ She was sad.
✅ She turned her face to the window. There was nothing outside.

❌ He was furious.
✅ He set the cup down on the table. Didn't slam it. But set it down heavy.
```

**Substitution list**: emotion → action instead of adjectives / atmosphere → environment / relationship → distance and orientation / psychology → body reactions

## 2. Sensory detail (≥ 3 dimensions)

At least 3 senses per scene:

| Sense | Use |
|---|---|
| Sight | light/shadow/color/shape/motion |
| Sound | texture/rhythm/silence |
| Smell | scent/season/memory |
| Touch | temperature/texture/pressure |
| Taste | food/drink/mouthfeel |

**Mix**: coffee's bitterness on the tongue + rain on glass + fingers over cold wood

## 3. Rhythm control

- Long passages: setup/description/psychology
- Short punches: action/turns/key moments
- Single-sentence paragraphs: emphasis/negative space
- Dialogue: acceleration
- Blank lines: before/after important moments

```
❌ Uniform paragraphs (no variation)
✅ Rhythm: She walked into the room. He sat by the window, looking tired. She crossed over and sat beside him. He said nothing. She said nothing either.
```

## 4. Negative space is power

- Before/after key dialogue / emotional climax / before turns / ending echoes
- Forms: blank line / single-sentence paragraph / ellipsis (sparingly)
- Don't overuse (dilutes)

## 5. Dialogue is character

- Every character speaks differently (age/job/education/region/personality)
- Never use dialogue to explain plot
- Subtext: mouth ≠ heart
- Silence = what's unsaid matters more

**5 dialogue jobs**: advance plot / reveal character / create tension / subtext / silence

## 6. Character building (4 dimensions)

| Dimension | Content |
|---|---|
| Exterior | clothing/posture/habitual motions |
| Speech | manner/vocabulary/rhythm |
| Psychology | motives/fears/desires |
| Relations | network with others |

**Sketching**: don't say everything / see people through action / through contradiction / through detail

## 7. Scene building (5 elements)

Space / time / atmosphere / objects / change

**Transitions**: action transition / time jump / sensory switch / no "meanwhile"

## 8. Plot rhythm

**4-part structure** (East) / **three-act** (West, 25/50/25)

**Hooks**: first 100 words must have one / every chapter ending must have one / not the same as cliffhanger TV

## 9. Point of view

- First person: strong immersion, limited
- Third: omniscient or limited
- Second: rare, strongly intrusive
- Multi-POV: switch per chapter / same event from multiple angles

## 10. Five strong endings

1. Echo the opening
2. Cut off abruptly
3. Ironic reversal
4. Long aftertaste
5. Theme resonance

**Counter-examples**: "happily ever after" / "finally understood" / "maybe that's life" / explaining everything

## 11. Anti-AI literary tells (10)

1. No "once upon a time" openings
2. No "my heart could not calm down"
3. No "happily ever after"
4. No piled ornate adjectives
5. No exclamation/ellipsis abuse
6. Don't explain every metaphor
7. No "in that moment, I finally understood"
8. No forced elevation
9. No "may you walk out of half your life"
10. No preaching

## 12. Editing in 4 steps

1. Cut 30% of words
2. Replace "very good" with specific detail
3. Read aloud for rhythm
4. Review after a night

## 13. Quick card

```
Show don't tell / senses ≥ 3 / rhythm varies / negative space at keys / dialogue is character / strong ending / no fizzle, no explaining
```

# Masters to Learn From

> Learn from someone to write like someone. Each master, one signature skill.

## Chinese

| Master | Learn | Representative work |
|---|---|---|
| Cao Xueqin | dialogue / foreshadowing | *Dream of the Red Chamber* |
| Eileen Chang | psychological subtlety / desolation / senses | *Lust, Caution* / *Little Reunions* |
| Lu Xun | short-sentence punches / national character | *Call to Arms* / *Wild Grass* |
| Shen Congwen | borderland lyricism / water-like prose | *Border Town* |
| Wang Zengqi | note-style fiction / plain human flavor | *Ordination* |
| Yu Hua | cold narration / violence aesthetics | *To Live* |
| Mo Yan | sensory explosion / density | *Big Breasts and Wide Hips* |
| Wang Xiaobo | ironic humor / speculation | *The Golden Age* |
| Wang Anyi | urban texture / long sentences | *Song of Everlasting Sorrow* |
| Su Tong | southern dampness / decadence | *Wives and Concubines* |
| Liu Zhenyun | circuitous talk / speech craft | *One Sentence Is Ten Thousand Sentences* |
| Can Xue | dream logic / subconscious | *Huangni Street* |
| A Cheng | minimalist dialogue / worldly innocence | *The Chess Master* |
| Shi Tiesheng | speculative lyricism / suffering | *Me and the Temple of Earth* |
| Chi Zijian | northern vastness / warmth | *The Last Quarter of the Moon* |
| Lilian Lee | bewitching imagery / Hong Kong style | *Farewell My Concubine* |

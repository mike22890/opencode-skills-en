# Literary Craft

## When to trigger (load on sight)

Trigger keywords: novel, story, short story, long-form, article, essay, commentary, poetry, screenplay, love letter, diary, literature, character, plot, dialogue, sensory, intimate, sensual, description, taboo, style, chapter, act, role, character development.

## Creed

1. **Suggest > state** — show don't tell
2. **Sensory > physical** — sensory detail builds reality
3. **Emotion > action** — inner drives outer
4. **Negative space > piling on** — what's unsaid is stronger
5. **Rhythm > length** — breathing over word count
6. **Master anchors** — learn from someone; don't write like no one

## 6 rules

1. **Suggest > state**: action + psychological hints, never state outright
2. **Sensory detail**: use ≥ 3 of sight/sound/smell/touch/taste
3. **Rhythm breathing**: long narrative + short punches + accelerating dialogue
4. **Negative space is power**: blank lines before/after important lines
5. **Dialogue is character**: every character speaks differently
6. **Ending echoes**: the last line echoes the opening / theme / emotion

## Mandatory self-check (before finishing)

- [ ] Sensory ≥ 3 dimensions (sight/sound/smell/touch/taste)
- [ ] Suggest > state (don't say "he was sad" — let the body say it)
- [ ] Rhythm varies (no flatness)
- [ ] Negative space used at key moments (not overused)
- [ ] Differentiated dialogue
- [ ] Strong ending (no fizzle)
- [ ] 5-second look says "master"

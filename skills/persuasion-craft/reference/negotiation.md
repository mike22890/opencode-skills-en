# 谈判（Voss 精简版）

## 7 大技巧

| 技巧 | 用法 |
|---|---|
| **镜像** | 重复对方最后几字（问号语气） |
| **校准** | "什么/怎么"代替"为什么" |
| **标签** | "似乎/看起来/听起来 + 你 + 情绪" |
| **锚定** | 先说数字（极端但合理） |
| **沉默** | 问完闭嘴（3-5 秒） |
| **不分胜负** | 不折中，找真问题 |
| **黑天鹅** | 找没说但真正在意的 |

## 流程

准备 → rapport → 信息收集 → 影响 → 成交

## BATNA

谈崩了能做什么？越强谈判力越强

## 类型

- **分配式**（固定资源）：锚定+不分胜负
- **整合式**（创造价值）：信息收集+找黑天鹅

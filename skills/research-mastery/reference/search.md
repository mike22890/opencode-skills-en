# 搜索进阶

## 搜索运算符（Google/Tavily 通用）

| 运算符 | 作用 | 例 |
|---|---|---|
| `"短语"` | 精确匹配 | `"quantum computing"` |
| `-词` | 排除 | `jaguar -car` |
| `site:` | 限定站点 | `site:github.com rust` |
| `filetype:` | 文件类型 | `filetype:pdf report` |
| `intitle:` | 标题包含 | `intitle:review` |
| `OR` | 或 | `react OR vue` |
| `before:/after:` | 时间 | `after:2026-01-01` |

## 垂直搜索源

### 学术/研究
- Google Scholar（引用数排序）
- arXiv / SSRN（预印本）
- PubMed（医学）
- 知网/万方（中文）

### 技术
- GitHub（代码 + issues + stars）
- Stack Overflow（问题解决）
- Hacker News（技术讨论）
- 官方文档（永远优先）

### 新闻/时事
- Google News
- 微博热搜 / 知乎热榜
- X（实时性最强）
- 路透/彭博（财经）

### 商品/评价
- 电商平台（京东/淘宝/Amazon）
- 什么值得买（中文评测）
- Reddit（真实用户讨论）
- YouTube 评测（视频实测）

## 深挖技巧

### 找原始来源
```
二手报道 → 找引用的原始研究/文件 → 读原文
```

### 找专业人士
```
搜索 "site:zhihu.com 领域词" 或 "site:reddit.com r/领域"
```

### 找反面观点
```
关键词 + "criticism" / "problems" / "缺点" / "反对"
```

### 找数据
```
关键词 + "data" / "statistics" / "报告" / "白皮书"
```

## 搜索失败时

1. **换语言**（中→英）
2. **换关键词**（同义词/上位词/下位词）
3. **换平台**（Google→Bing→垂直站）
4. **找专家**（谁研究这个？搜他的名字）
5. **找社区**（Reddit/知乎/论坛问）

## 速查卡

```
主词+限定+同义词 / 4 轮搜索（广→深→验→补）
垂直源：学术/技术/新闻/商品
深挖：原始来源/专业人士/反面/数据
失败：换语言/换词/换平台/找专家
```
